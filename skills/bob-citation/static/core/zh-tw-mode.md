# 台灣繁中作業模式

使用者以台灣繁體中文提問是預設情境。不論輸入語言，遵守下列規則：

## 語言分工

- **理解**：接受中文段落、中文主張、中英混排的參考文獻清單。
- **檢索**：一律用英文概念詞與 MeSH 詞查 PubMed 與 Crossref。翻譯的是科學概念，不是逐字翻句子；縮寫與標準名詞（SUS、RAG、LLM、NP、OSCE、Tanner）保持原樣。
- **報告**：繁體中文。表格欄位名用中文，文獻本身的標題、作者、期刊名維持原文，不翻譯。
- **匯出檔**：RIS／BibTeX 內容全部維持來源語言，不加中文註記，避免匯入後汙染欄位。

## 用語

- 使用台灣學術用語：資料（不是數據，統計語境除外）、資訊、軟體、品質、最佳化、專案、回饋、使用者、程式、欄位、網路、預設、期刊投稿、審查委員、修訂後再審、支持文獻。
- 不使用簡體字，不使用中國大陸平台名稱。書目管理只提 EndNote、Zotero；中文資料庫只提華藝 Airiti、臺灣博碩士論文知識加值系統。
- 中文段落用全形標點；引用括號用半形，例如 （Lyu et al., 2022）→ 正確寫法是 (Lyu et al., 2022)。

## 支持等級用語（find-support）

| 等級 | 中文標籤 | 意思 |
|---|---|---|
| direct | 直接支持 | 該文獻直接檢驗同一關係、介入或方法，結果與句子一致 |
| partial | 部分支持 | 支持句子的一部分、較窄的族群或相鄰的結果 |
| background | 背景支持 | 提供領域脈絡或先前觀察，不支持句子的特定主張 |
| contradictory | 相反或限縮 | 與句子衝突或限縮其適用範圍，可放在討論或限制 |
| metadata-only | 僅看過書目 | 標題看起來相關，但尚未讀摘要，不可引用 |

明確用中文標出過度宣稱：「此句寫的是因果，文獻只支持相關」「文獻族群是腫瘤病人，句子談的是護理學生」。

## 嚴重度用語（verify）

- 🔴 必須修正、🟡 建議核對、🟢 僅供參考、❓ 無法驗證。
- 總判定：✅ 已驗證、⚠️ 建議核對、❌ 必須修正、❓ 無法驗證。

## 給台灣論文的提醒

- 國防醫學院碩士論文與台灣護理期刊都用 APA 7；中文文獻的 APA 格式（作者中文姓名、期刊中文名、卷期）交 `apa7-master`。
- 台灣中文期刊文獻多半沒有 Crossref DOI 或用華藝 DOI，`verify_dois.py` 會回 404；這不代表文獻不存在，改用 WebSearch 查期刊官網或華藝，並標「以官網為準，查核日期 YYYY-MM-DD」。
