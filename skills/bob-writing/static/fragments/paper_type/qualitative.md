# 論文類型：質性研究（qualitative）

質性研究回答的是「這個經驗或現象對當事人而言是什麼、如何發生、在什麼脈絡下有意義」，不是「有沒有效」。讀者的核心問題是：這些主題真的來自資料嗎？我能信任分析歷程嗎？能轉移到我的場域嗎？

## 論證鏈

`現象與脈絡 -> 為何需要質性取向（既有量性證據無法回答的問題）-> 方法論取向（現象學／紮根理論／主題分析／內容分析／敘事）-> 取樣邏輯與資料飽和 -> 資料收集情境 -> 分析歷程（可追溯）-> 主題與引文 -> 可信賴性 -> 反身性 -> 有邊界的貢獻`

任一環缺漏就標為缺漏，不要用文字繞過去。最常缺的是「為何需要質性取向」與「分析歷程可追溯」。

## 起草順序

1. 結果：先把主題、次主題、代表引文整理成表，再寫敘述
2. 方法：對照 COREQ 或 SRQR 的項目逐一補齊（準則選擇先問 `equator-guideline-finder`）
3. 緒論：回頭框出「既有文獻知道什麼、不知道什麼、為何要問當事人」
4. 討論：主題與文獻對話，說明轉移性
5. 摘要：最後寫

## 各節段落任務

### 緒論
- 現象在臨床或教育場域的樣貌，用具體情境開場，不用宏大背景。
- 既有量性研究說了什麼、留下什麼「為什麼」與「如何」沒回答。
- 研究目的用「探討」「描述」「瞭解」，不用「驗證」「檢驗」。

### 方法
- 方法論取向與哲學立場一句話講清楚，並與資料分析方法一致（例如：說用現象學就不能只做內容分析的次數統計）。
- 取樣：立意取樣或理論取樣的具體條件、招募管道、樣本數與飽和判準（何時停止、由誰判定）。
- 資料收集：訪談大綱如何發展、訪談時長與地點、是否錄音逐字稿、放聲思考的提示語。
- 分析：明確步驟（例如 Braun 與 Clarke 的六步驟、Colaizzi 七步驟），編碼者人數、歧見如何處理、軟體（若有）。
- 可信賴性：依 Lincoln 與 Guba 四準則逐一寫「做了什麼」，不是列名詞：
  - 可信性（credibility）：延長接觸、同儕檢核、參與者回饋核對（member checking）
  - 可轉移性（transferability）：厚實描述場域與參與者
  - 可靠性（dependability）：稽核軌跡、編碼簿版本
  - 可確認性（confirmability）：反身日誌、研究者立場聲明
- 反身性：研究者與參與者的關係（例如研究者本身是該單位的專科護理師）、可能的影響、如何處理。

### 結果
- 先給參與者特性表（編碼、年齡區間、年資、單位），不揭露可辨識資訊。
- 主題結構先總覽（主題表或圖），再逐一敘述。
- 每個主題的段落任務：主題定義一句 → 主題內的變異 → 代表引文 → 引文後一句連回主題。
- 不在結果解釋或引用文獻；解釋留給討論。

### 討論
- 每個主題與既有文獻的關係：一致、延伸、矛盾。
- 說明轉移性的條件，而非宣稱普遍性。
- 限制來自研究內部：取樣範圍、單一場域、訪談者即熟人、資料收集時機。

## 引文呈現規則

- 每則引文標示參與者代碼與必要脈絡，例如（P03，內科 NP，年資 8 年）；代碼制度全文一致並寫進術語帳。
- 引文長度以能呈現主題為限；刪節用「……」或［……］，補充說明用［ ］，不改動原話語氣。
- 每個主題至少有兩位不同參與者的引文支撐；只有一人說過的內容標為個案觀點，不升格為主題。
- 引文是證據，不是裝飾：引文之前要有主張，之後要有連結句。連續堆疊三則以上引文而無敘述是常見失敗。
- 台語或口語逐字稿翻成書面語時，保留原意並在方法說明處理方式。
- 中文論文引文用另起段落、縮排或標楷體區隔；英文投稿依期刊規定（多為縮排或斜體）。

## 動詞校準

- 可用：「參與者描述」「浮現」「反映」「呈現」「歸納出」「指出」。
- 避免：「證明」「證實」「顯著」「有效」「多數（給比例）」。若要報告人數，寫「12 位參與者中有 9 位提到」並在方法說明為何計數。
- 英文：`participants described`, `emerged`, `reflected`, `was characterised by`；避免 `proved`, `significantly`, `the majority (without n)`。

## 常見失敗模式

- 主題只是訪談大綱問題的重述（問什麼就得到什麼主題）。
- 主題之間互相重疊，或主題名稱是抽象名詞而非有內容的句子。
- 可信賴性四準則只列名詞，沒有實際作為。
- 引文沒有代碼、沒有連結句、或一則引文同時被兩個主題引用。
- 結果與討論混在一起：結果段落出現文獻引用。
- 用量性語言包裝質性資料（「顯著」「大多數」「比例」）。
- 樣本數只寫數字，沒有飽和判準。
- 研究者立場（例如同時是參與者的同事）沒有揭露。
