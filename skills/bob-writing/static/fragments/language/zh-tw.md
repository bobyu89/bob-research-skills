# 語言：直接以學術中文撰寫（zh-tw）

使用者要的是台灣繁體中文的論文正文（碩論、護理雜誌、護理研究、台灣專科護理師學刊、醫學教育）。慣例總表見 `../../../../bob-shared/core/zh-tw-academic-conventions.md`；本檔是撰寫時的動作層。

## 標點與排版

- 中文段落用全形標點：，。：；（）「」、。
- 引用括號用半形：（Tanner, 2006）、（王小明，2020）。中文文獻作者與年份間用全形逗號，英文用半形逗號加空格。
- 數字、英文、統計符號用半形；中英文之間習慣加一個半形空格（例如「SUS 分數」），全文一致即可。
- 統計符號斜體：*M*、*SD*、*t*、*p*、*F*、*r*、*n*；希臘字母不斜體。
- 百分比寫「25%」不寫「百分之二十五」；小數點前的 0 依 APA：可能超過 1 的數值寫 0.85，不可能超過 1 的（*p*、*r*、α）寫 .85。
- 表題在上「表 3-1　研究工具一覽」，圖說在下「圖 3-1　研究架構圖」，表號與表題間一個全形空格。

## 術語

- 英文術語第一次出現寫「中文（English, 縮寫）」，例如「系統可用性量表（System Usability Scale, SUS）」；之後只用中文或縮寫，全文擇一。
- 中文定名鎖進術語帳；同一概念不換字（「臨床推理」不與「臨床推論」「臨床思辨」混用）。
- 量表、理論、模型名稱依台灣既有中譯（若有已發表的中文版量表，用該版本名稱）。
- 避免大陸用語：資料（非數據，統計語境可用數據）、軟體、資訊、品質、最佳化、專案、回饋、使用者、程式、欄位、網路、預設、指導教授、口試、計畫書、修訂、審查委員。完整對照見共用檔。

## 句法

- 一句一個命題；中文句子超過 50 字先考慮拆。
- 少用「被」字句；能用主動就主動（「研究者以立意取樣招募…」而非「參與者被招募…」）。
- 去翻譯腔：「進行了分析」→「分析」；「對於…而言」→「對…」；「透過…的方式」→「以…」；「是…的」句式減少；「一個」「一種」多數可刪。
- 主語一致：學位論文常用「本研究」「研究者」；期刊依刊物慣例（多數用「本研究」）。不要一段內「我們」「本研究」「研究者」混用。
- 連接詞要表達邏輯關係（然而、因此、相較之下、換言之），不用「另外」「此外」堆疊並列。
- 「顯著」只用於統計顯著並附 *p* 值；口語的「顯著」改「明顯」「大幅」。

## 段落

- 主題句在段首。
- 一段一個任務（背景／缺口／方法／結果／比較／意涵／限制）。
- 段落長度以 150 到 300 字為常態；超過 400 字先拆。
- 不用「綜上所述」「值得注意的是」「不可否認」等開頭；直接寫內容。這些是 AI 腔與套話的標記。

## 動詞校準（中文）

| 證據強度 | 可用動詞 |
|---|---|
| 直接強證據（有對照、效果量） | 證實、顯示、支持 |
| 描述觀察 | 發現、呈現、反映、指出 |
| 趨勢或間接 | 提示、暗示、傾向 |
| 未驗證的解釋 | 推測、可能、或許、似乎 |
| 質性資料 | 參與者描述、浮現、歸納出 |

橫斷設計不寫「導致」「影響」（因果），改「相關」「關聯」。單組前後測不寫「有效」，寫「改善」並註明無對照。

## 章節慣用語（碩論）

- 緒論：「本研究旨在…」「研究目的如下：」
- 方法：計畫書用「本研究將採…」「擬以…」；完成本改「本研究採…」「以…」。
- 結果：「結果顯示…」「達統計顯著（*p* < .05）」「未達顯著差異」。
- 討論：「本研究發現…，與…的結果一致」「可能的解釋是…」「此結果提示…」。
- 結論與建議：「本研究建議…」（具體對象與作法）。

## 常見失敗模式

- 全形與半形標點混用；英文逗號後沒有空格或中文逗號後有空格。
- 同一量表三種寫法。
- 「本文」「本研究」「筆者」「我們」混用。
- 「進行」「透過」「的」過多。
- 引用括號用全形。
- 用「數據」指質性資料；用「軟件」「用戶」等大陸用語。
- 每段開頭套話。
