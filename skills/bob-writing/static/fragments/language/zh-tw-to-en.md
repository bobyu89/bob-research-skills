# 語言：中文筆記轉英文稿（zh-tw-to-en）

使用者的輸入是繁體中文、中英夾雜、或以中文筆記整理的材料，目標是英文期刊稿件。

## 翻譯意圖，不翻譯句法

中文學術筆記常把背景、動機、方法、意涵塞在一個長句。寫英文之前，先把每條筆記拆成：

- 主張（claim）
- 證據（evidence）
- 條件（condition）
- 比較（comparison）
- 意涵（implication）
- 限制（limitation）

然後依英文該節要求的順序寫，不依中文句子的順序。

## 台灣作者常見的英文問題與修法

| 中文草稿或直譯模式 | 英文修法 |
|---|---|
| 「隨著…的發展／近年來」開場 | 刪掉，直接從具體問題或對象開始；`In recent years` 幾乎總是可刪 |
| 「越來越多的研究」 | `A growing body of evidence` 只在真的引三篇以上時用；否則寫具體研究 |
| 「顯著提升／明顯改善」沒有比較基準 | 補比較組與效果量，或把 `significantly` 改 `notably`；`significant` 只用於統計顯著 |
| 「首次／創新」沒有範圍 | `To our knowledge, no study has examined X in [scope]`；不用 `first ever` |
| 「本研究透過…進行探討」 | `This study examined …`；刪 `through the way of`、`conduct an investigation on` |
| 「研究對象為…」 | `Participants were …`；不用 `research objects`、`subjects`（除非期刊要求） |
| 「護理人員」直譯 `nursing staffs` | `nurses` 或 `nursing staff`（不可數） |
| 「病人家屬」直譯 `patients' family` | `family caregivers` 或 `family members of patients` |
| 「專科護理師」 | `nurse practitioners (NPs)`，台灣語境可註 `in Taiwan` |
| 「問卷調查法」 | `a questionnaire survey`；不用 `questionnaire survey method` |
| 「研究」當可數名詞 `a research`、`researches` | `a study` / `studies`；`research` 不可數 |
| 冠詞缺漏（`SUS score was`） | `The SUS score was`；專有量表名前加 `the` |
| 單複數未標（`participant reported`） | 逐一決定：`participants reported` / `each participant` |
| 時態未標 | 做過的事與發現用過去式；已建立的事實與圖表描述用現在式 |
| 逗號黏句（`…was high, it suggests…`） | 拆成兩句或加連接詞：`…was high, which suggests…` |
| 「對…而言」→ `for … , it is …` 的主題句 | 改主詞動詞受詞：`Nurses found …` |
| 每句以 `This study` / `We` 開頭 | 輪流以結果或對象當主詞 |
| 「的…的…的」堆疊修飾 | 拆成關係子句或兩句 |
| 名詞化堆疊（`the improvement of the performance of`） | 改動詞：`improved performance` |
| 「可以」直譯 `can` 表推測 | 推測用 `may` / `could`；`can` 表能力 |
| `According to the results, it shows that` | `The results show that` |
| `more and more` | `increasingly` 或給數字 |
| `do the research` / `make a study` | `conducted the study` |
| 中文標點殘留（全形逗號、頓號） | 全部改半形，頓號改逗號或 `and` |
| 量表名稱直譯 | 用原始英文量表名，首次出現附縮寫 |
| 機制從相關推得 | `is associated with`、`suggests`，或要求機制證據 |
| 結果與意涵混寫 | 觀察放 Results，意義放 Discussion |
| 「等」`etc.` 結尾 | 列完或用 `such as` 開頭 |

## 句子與段落

- 草稿句長 10 到 30 字（英文字）；一句一個命題。
- 主詞動詞受詞順序優先；避免介系詞鏈。
- 一段一個訊息；第一句是主張；後續句與前句有明確關係。
- 不用破折號當連接詞；用逗號、括號或短句。

## 動詞校準

- `show` / `demonstrate`：有直接強證據。
- `suggest` / `indicate`：趨勢或間接證據。
- `may` / `could`：合理但未驗證。
- 避免行銷動詞 `leverage`、`empower`、`enable`（除非有具體資訊）。
- 質性：`participants described`、`emerged`、`reflected`。

## 輸出慣例

先給潤好的英文，再用簡短繁中說明主要結構決定（哪些句子合併、拆分、搬移、改弱）。這讓作者不必從頭重讀英文就能核對意圖。

英文術語與中文原文的對應寫進術語帳，避免同一概念英文出現兩種譯法。

## 交接

- 已有英文草稿只需句子層潤飾：`bob-polishing`。
- 更多修法與邊緣案例：`references/chinese-author-workflow.md`。
- 英文參考文獻格式：`apa7-master`。
