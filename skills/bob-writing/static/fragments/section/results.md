# 章節：研究結果（Results，撰寫）

適用於健康科學、護理、醫學教育、數位健康研究的結果章節與碩論第四章。演算法或系統效能比較型論文（baseline、ablation、benchmark）改用 `section/experiments.md`。

## 預設證據階梯

`樣本或參與者特性 -> 依研究問題或假設逐一回答（主要結果）-> 次要結果 -> 質性主題（若有）-> 整合（若為混合方法）-> 每個單元收在有邊界的推論`

依研究設計調整：

- 類實驗或 RCT：先流程圖（收案、分派、流失），再基線比較，再主要成效，再次要成效。
- 橫斷或相關：描述統計 → 雙變項 → 多變項。
- 質性：參與者特性 → 主題總覽 → 逐主題敘述與引文（見 `paper_type/qualitative.md`）。
- 混合方法：量性股 → 質性股 → joint display（見 `paper_type/mixed-methods.md`）。
- DBR：依迭代輪次或依設計原則，最終版整體評估獨立一節（見 `paper_type/dbr.md`）。

## 起草前

- 載入 `../../../../bob-shared/core/main-text-discipline.md`，把每個分析分類：核心發現、必要支撐、限定條件、穩健性、附錄細節。主文只放前三類，其餘記錄去向。
- 載入 `../../../../bob-shared/core/results-discussion-escalation.md`，確認每個小節推進一個新主張，而不是用不同數字重複同一個主張。
- 結果順序對應緒論的研究問題順序；每個研究問題在結果都要有回答，每個結果都要有對應的問題。

## 每段的段落任務

1. 主張句：這段要回答哪個問題、答案是什麼（例如「介入後 SUS 分數達可接受等級」）。
2. 證據句：統計量、效果量、信賴區間，或主題與引文；指向表號或圖號。
3. 邊界句（可選）：在什麼子群或條件下不成立，或樣本限制。

不寫解釋、不引文獻、不與其他研究比較；那是討論的工作。允許直接回答當前分析的簡短推論（「顯示」「反映」），但不擴展成機制或意涵。

## 統計呈現

- 格式依 APA 第七版：*t*(df) = x.xx, *p* = .xxx, *d* = x.xx；*F*(df1, df2)；χ²(df, *N* = n)；*r*；β；95% CI [下限, 上限]。細節與表格轉換交 `bob-statistics`。
- 正文與表格不重複同一組數字：正文寫主要統計量與方向，表格放完整數值。
- *p* 值報告實際值（*p* = .032），小於 .001 寫 *p* < .001；不寫 *p* = .000。
- 效果量與信賴區間和 *p* 值一起出現。
- 描述性結果用「平均 ± 標準差」或「*M* = , *SD* = 」，全文一致。
- 量表分數要附可能範圍與詮釋基準（例如 SUS 0 到 100，68 分以上為高於平均），基準來源在方法章交代。

## 表格與圖

- 表題在上、圖說在下；碩論編號「表 4-1」「圖 4-1」，期刊依規定。
- 每個表或圖在正文至少被指引一次，且指引句要說結論不只說「如表 4-1」。
- 表格自足：縮寫在表註解釋，統計符號斜體，小數位數一致。
- 不要為每個變項各做一表；同類結果併表。

## 質性與混合資料

- 主題呈現：主題表（主題／次主題／代表引文代碼）先於敘述。
- 引文規則見 `paper_type/qualitative.md`。
- 混合方法的整合表放在兩股結果之後、討論之前。

## 動詞校準（結果專用）

- 中文：「達到」「高於」「低於」「增加」「無顯著差異」「浮現」「參與者描述」。
- 英文：`increased`, `was higher than`, `did not differ`, `reached`, `emerged`。
- 避免在結果使用「證實」「有效」「顯著改善」（除非 *p* 與效果量同時支持且有對照）。
- 「顯著」只用於統計顯著並附 *p* 值；描述性差異用「較高」「較大」。

## 常見失敗模式

- 結果段落解釋原因或引用文獻。
- 正文、表格、圖說三處重複同一組統計量。
- 只報 *p* 值，沒有效果量與信賴區間。
- 表格指引句沒有結論（「結果如表 4-2 所示」）。
- 研究問題順序與結果順序不一致。
- 把流失、遺漏值處理、基線不平衡藏起來。
- 質性結果只有主題名稱沒有引文，或只有引文沒有主張。
- DBR 只報最終版本。
- 每段一個主張但沒有對應證據，或每段有證據但沒有主張。

## 常見口試委員意見

- 「結果跟研究目的對不起來」：用表對應研究目的、研究問題、對應結果小節、表號。
- 「表格太多」：併表、次要分析移附錄。
- 「這是結果還是討論」：把解釋句搬到第五章。
- 「效果量呢」：補 *d*、η²、OR 及 95% CI。
