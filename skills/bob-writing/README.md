# `bob-writing`：健康科學論文撰寫

依作者提供的主張、結果、圖表、筆記或中文草稿，起草或重組健康科學、護理、醫學教育、數位健康論文的章節、國防醫學院碩士論文各章，以及首次投稿材料。改造自上游 skill 集（來源與逐檔變更見 [UPSTREAM.md](UPSTREAM.md)）。

## 用途

- 建立一句話論證、術語帳、段落地圖，經確認關卡後再起草，逐段修訂而非整篇重寫。
- 撰寫或重建：標題、結構式或非結構式摘要、緒論、文獻探討、研究方法、研究結果、討論、結論。
- 碩論五章（緒論、文獻探討、研究方法、研究結果、討論與結論）的段落任務與口試委員常見意見。
- 論文類型手冊：research、methods、hypothesis、algorithmic、review，以及新增的 qualitative（可信賴性、引文呈現）、mixed-methods（joint display）、dbr（設計原則→迭代→評估→設計知識）。
- 結果配置：核心發現、必要支撐、限定、附錄，壓縮成最短充分證據鏈。
- 直接以學術中文撰寫（全形標點、統計符號、中英術語並列、去翻譯腔）或把中文筆記轉成英文稿（台灣作者常見英文問題修法）。
- 首次投稿材料：投稿信（英文與中文 Markdown 範本）、標題頁、highlights、作者貢獻、資料可用性、倫理與 AI 使用揭露、推薦審稿人、投稿就緒稽核。
- 期刊動作層：健康科學通用、國際護理期刊、JMIR 系列、台灣中文護理期刊、國防醫學院碩論格式。

## 觸發語

幫我寫緒論、寫討論、寫結論、寫摘要、結構式摘要、研究目的怎麼寫、論證架構、段落安排、證據鏈、碩論第一章、碩論第三章、計畫書前三章、文獻探討怎麼組織、結果章節、討論與結論、標題怎麼下、投稿信、cover letter、標題頁、作者貢獻、資料可用性聲明、推薦審稿人、首次投稿、投稿材料、主文太長怎麼精簡、這段流不流暢。

## 範例提示詞（台灣情境）

1. 「我的碩論是 DBR，系統是結合生成式 AI 與 RAG 的專科護理師臨床推理學習系統，理論框架是 Tanner 臨床判斷模型。這是三輪迭代的紀錄表和最後一輪的 SUS 分數與訪談主題，幫我規劃第四章研究結果的架構，先給段落地圖再寫。」
2. 「我要投護理雜誌，這是中文摘要草稿和主要統計結果（t 檢定、效果量）。請用結構式摘要重寫，背景、目的、方法、結果、結論各一到三句，全形標點，並列出哪些數字需要我補。」
3. 「幫我寫投稿 Nurse Education Today 的 cover letter。研究是專科護理師學生使用 AI 臨床推理系統的可用性與學習經驗，IRB 已由醫學中心核准，論文改寫自碩論。只用我給的事實，缺的用 AUTHOR_INPUT_NEEDED 標出來。」

## 你需要提供

- 核心主張、圖表、關鍵結果、研究設計事實、目標讀者。
- 目標章節、長度、輸出語言、必須保留的術語與中英定名。
- 已確認的引用、限制條件、不能新增的結論。

## 產出

- 章節大綱、段落任務表、主張與證據對照、可貼上的正文。
- 結果配置表、刪除或取代紀錄、主文壓縮前後字數（需要時）。
- 碩論章節的口試委員可能追問清單。
- 首次投稿材料包、投稿信、缺漏資訊清單、`ready / ready_with_author_checks / blocked` 狀態。

## 與既有 skill 的分工

| 需求 | 交給 | 本 skill 的角色 |
|---|---|---|
| 整章 .docx、多篇文獻整合成段、APA 內文引用、AI 痕跡消除 | `academic-writing` | 先給論證架構與段落任務，再交接 |
| 參考文獻格式（APA 7） | `apa7-master` | 不處理 reference list |
| 含系統性檢索的範疇性回顧 | `scoping-review-master` | 不處理 PCC、檢索策略、PRISMA-ScR |
| 概念分析 | `concept-analysis-master` | paper_type 不含概念分析，直接轉交 |
| 報告準則選擇 | `equator-guideline-finder` → 對應 `*-master` | 先問準則再撰寫 |
| 混合方法設計 | `mixed-methods-research` | 只管怎麼寫 |
| 句子層潤飾 | `bob-polishing` | 本 skill 管架構 |
| 找文獻、驗證 DOI | `bob-citation` / `citation-verifier` | 不查文獻 |
| 統計格式與表格 | `bob-statistics` | 只指出該放什麼統計量 |
| 圖表 | `bob-figure` | 只決定圖表在論證中的位置 |
| 修訂回覆、口試意見對照表 | `bob-response` | 只管首次投稿 |
| 模擬審稿 | `bob-reviewer` / `academic-peer-reviewer` | 提供自我審查清單 |
| 研究日誌、迭代紀錄 | `bob-research-log` | 讀取其 iteration-log 作為 DBR 結果的輸入 |
| 講人話 | `speak-human-tw` | 學術語域以外轉交 |
| 檔案輸出 | `docx` / `pptx` / `xlsx` / `pdf` | 產生文字後交接 |

## 邊界

- 不替作者虛構結果、統計、機制、文獻或 IRB 案號。
- 不憑記憶寫死期刊字數與圖表上限；具體數字標「以期刊官網為準，查核日期」。
- Nature 系列 fragment 為上游保留，非預設且未經本集驗證。
