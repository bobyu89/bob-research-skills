# bob-response：審稿意見回覆

把退修信、審稿意見與你的修改筆記，整理成一套可稽核的修訂回覆包：內部追蹤總表、每位審稿人各自一份的逐點回覆表、修訂版 cover letter、修改處標示的修改稿摘錄。另有「口試委員意見回覆表」模式，處理碩士論文口試後的委員意見。

語境：護理、醫學教育、數位健康期刊（JAN、IJNS、NET、NEP、JNR、CIN、JMIR 系列、BMC Medical Education）與台灣中文期刊（護理雜誌、護理研究、台灣專科護理師學刊、醫學教育）。引用格式 APA 第七版。輸出繁體中文或英文。

## 用途

- 解析退修信：稿件編號、決定類型、編輯指示、各審稿人報告邊界、要繳的檔案、期限、可見性規則。
- 先確認是主要修訂（Major Revision）還是次要修訂（Minor Revision），再套用對應策略；不明時會先問你。
- 把意見拆成穩定編號：`E.1`（編輯）、`R1.1`、`R2.3`（審稿人）；口試模式用 `C1.1`、`A.1`。
- 預設審稿人互盲：內部保留總表，給每位審稿人的回覆各自獨立，不洩露另一位的意見、編號、建議或回覆。
- 每一條意見都分類「回應動作」「工作狀態」「所需輸入」「預期產出」「是否阻斷定稿」，宣稱已修改的必須有可檢視的修訂文字。
- 審稿人漏看文中已有內容時，當成呈現不清，改文稿而不是回「文中已說明」。
- 回覆信完整回答，文稿修改只保留讀者需要的最短文字；每一處新增都檢查能否取代、壓縮或移到附錄。
- 稽核既有草稿：漏回、過度道歉、全盤接受、回覆與修改不一致、缺頁碼、捏造合規。
- 產出 Markdown／Word 版逐點回覆表（Reviewer／Comment／Response／Location of change／Status）與 cover letter；LaTeX 範本保留為選用。
- 口試委員意見回覆表（委員／意見／修改內容／頁碼），計畫書口試或學位論文口試皆適用。

## 觸發語

回覆審稿意見、審稿回覆、逐點回覆、rebuttal、修訂說明、修訂說明表、退修信、審查意見回覆、主要修訂、次要修訂、修改後再審、修改處標示、紅字標示、cover letter 修訂版、修訂版投稿信、口試委員意見回覆表、口試意見修改對照表、response to reviewers、point-by-point response。

## 範例提示詞

1. 「這是 Nurse Education Today 的退修信和兩位審稿人的意見（貼上）。審稿人一質疑 12 位專科護理師的 SUS 樣本數太少，審稿人二問 RAG 系統的幻覺風險怎麼控制。我們的修改筆記在下面，幫我做逐點回覆表和 cover letter，英文，另外給我中文核對清單。」
2. 「護理雜誌通知修改後再審。附審查委員甲、乙的意見和我改好的稿子（紅字版）。幫我產出修訂說明表，檢查每一條回覆有沒有對到頁碼，還有回覆裡寫的修改是不是真的在稿子裡。」
3. 「計畫書口試通過了，這是三位委員和指導教授的意見（口試筆記整理）。幫我整理成口試委員意見回覆表，欄位是委員、意見、修改內容、頁碼；頁碼我還沒更新目錄，先留佔位符。另外提醒我哪些意見會動到 IRB 送審版本。」

## 你需要提供

- 退修信、審稿意見、修訂要求，或既有的回覆草稿；口試模式則提供委員意見與口試類型。
- 若退修信沒寫明，告訴我這是主要修訂還是次要修訂。
- 已完成或計畫完成的分析、資料、圖表、修訂後文字與位置（頁、行、段）。
- 目標期刊、稿件編號、題目、要繳交的檔案格式。

## 產出

- 回覆策略摘要（決定類型、任務模式、主要風險、就緒狀態）。
- 內部／編輯總表（標示非審稿人可見）。
- 每位審稿人一份的逐點回覆表或回覆信；修訂版 cover letter（要求時）。
- 文稿修改清單、缺漏資訊清單、風險標示、中文核對。
- 口試模式：口試委員意見回覆表、論文修改清單、IRB 修正案提醒。
- 需要 Word 檔時交 `docx`。

## 邊界

- 不捏造實驗、分析、頁碼、圖版、統計結果、引用文獻或編輯指示。
- 給審稿人的檔案不出現「另一位審稿人也提到」「見我們對審稿人二的回覆」。
- 不用「我們已在文中說明」回敬審稿人。
- 不把主文寫成預防性的審稿回覆。
- 需要你確認的事項用繁中列在「中文核對」，不直接寫成事實。
- 期刊格式細節以官網為準（本 skill 內的查核日期 2026-09-06）。
