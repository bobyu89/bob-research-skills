# 台灣中文期刊的修訂回覆慣例

投稿台灣中文期刊（護理雜誌、護理研究、台灣專科護理師學刊、醫學教育等）並收到退修通知時載入本檔。本檔整理的是常見慣例與本 skill 的預設做法；各刊格式細節時有更動，凡涉及具體規定處一律「以期刊官網為準（查核日期 2026-09-06）」，送出前請再查一次投稿須知與退修通知本身。

## 一般慣例

| 項目 | 常見做法 | 本 skill 預設 |
|---|---|---|
| 回覆文件名稱 | 「修訂說明」「修改說明表」「審查意見回覆表」「答覆審查意見」 | 依退修通知用語；通知未寫時用「修訂說明表」 |
| 回覆形式 | 表格為主：審查委員／審查意見／修改說明／修改處頁碼（或頁、行） | 使用 `templates/response-letter.md` 的繁中版 |
| 一稿一表 | 每一次修訂各附一份新的修訂說明表；第二輪以後仍逐條回覆該輪意見，不沿用上一輪的表 | 每一輪獨立產表，編號加輪次（例如 R1-1.1 表示第一輪審稿人一第一條）；使用者未指定時用 `R1.1` |
| 審查委員編號 | 通知通常寫「審查委員一」「審查委員二」或「審查者甲」「審查者乙」 | 沿用通知的稱呼，不自行改為 Reviewer 1 |
| 修改處標示 | 修改稿中以底線、紅字或黃底標示修改處；有些期刊要求「追蹤修訂」版加「清稿」版 | 先查退修通知；未寫時預設「紅字」，並另附清稿 |
| 語言 | 中文期刊的回覆表用繁體中文；英文審查意見可保留英文原文，回覆用中文 | 全形標點；統計符號、p 值、效果量與引用括號依 APA 7 用半形 |
| 語氣 | 「感謝審查委員的指正」一句即可；直接說明改了什麼、改在哪裡 | 一句感謝，不重複道歉；不同意時「經審慎考量，本研究……」加理由 |
| 中英摘要 | 若修訂涉及摘要，中英摘要要同步修改並同步標示 | 修改清單中把「中文摘要」與「英文摘要」列為兩個項目 |
| 主要與次要修訂 | 通知常寫「修改後再審」「修改後刊登」「修改後由主編決定」 | 「修改後再審」對應主要修訂策略；「修改後刊登」「修改後由主編決定」對應次要修訂策略；不明時仍問使用者 |
| 繳交期限 | 通知會給修改期限；逾期可能視為撤稿或重新投稿 | 從通知擷取期限並寫進回覆策略摘要 |
| 參考文獻 | 多數期刊採 APA 第七版（部分刊有自訂細節） | 文獻格式交 `apa7-master`；回覆表只寫「已新增文獻 X，見參考文獻第 X 頁」 |

## 修訂說明表欄位建議

```text
| 編號 | 審查委員意見（原文） | 修改說明 | 修改處（頁／行／段） |
|---|---|---|---|
| 委員一－1 | ...... | 感謝委員指正。已將……修改為……。 | 第 6 頁第 2 段（紅字） |
```

若期刊要求「修改前／修改後」對照，欄位改為：編號／審查意見／修改前文字／修改後文字／頁碼。修改後文字用斜體（Word 中用斜體樣式）。

## 各刊特別注意（以官網為準，查核日期 2026-09-06）

以下只列本 skill 能確認的「查核方向」，不寫死格式與數字：

- 護理雜誌（The Journal of Nursing，台灣護理學會）：查投稿須知中的「修改稿繳交」段落，確認是否需要「修改說明表」以及修改處標示方式；確認中英文摘要字數與關鍵字數量是否隨修訂變動。
- 護理研究（The Journal of Nursing Research，JNR）：JNR 為英文期刊，退修流程與英文期刊相同，回覆信用英文；查官網對 point-by-point response 與 marked copy 的要求。
- 台灣專科護理師學刊：查投稿須知與退修通知的回覆表格式；確認是否要求附「修改對照表」。
- 醫學教育（台灣醫學教育學會）：查投稿須知的修訂回覆規定。

不確定時，把「以期刊官網為準（查核日期 2026-09-06）」寫進回覆策略摘要的風險欄，提醒使用者送出前再查一次。

## 常見錯誤

- 把英文期刊的 `Dear Reviewer` 信體直接翻成中文；中文期刊多數要表格，不要信體。
- 回覆表寫「已修改」但不給頁碼。
- 修改稿標了紅字，但清稿忘了把紅字轉回黑字。
- 第二輪回覆沿用第一輪的表，沒有針對第二輪新意見逐條回覆。
- 中文摘要改了，英文摘要沒改（或反之）。
- 回覆表用簡體字或大陸用語（數據、反饋、返修）。

## 與 `bob-shared` 的關係

台灣中文期刊的投稿格式（中英摘要並列、APA 中文格式、關鍵字）屬 `bob-shared/journal-formats/taiwan-nursing.md` 的範圍；該檔完成後以其為準，本檔只管「修訂回覆」這一段。
