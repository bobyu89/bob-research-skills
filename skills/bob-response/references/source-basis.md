# Source basis

Use this file to keep `bob-response` grounded in public, near-primary publication-process
sources. Source labels distinguish formal policy from journal instructions and editorial advice.
Journal pages change; every entry below carries the date it was last checked, and the current
journal page always wins.

## Source hierarchy

1. Target journal instructions and the specific editor decision letter.
2. ICMJE Recommendations and COPE guidance on peer review and author responsibilities.
3. Publisher-level peer-review and revision-process pages for the target journal's publisher
   (Wiley, Elsevier, JMIR Publications, Springer Nature, BMC, Taiwan Nurses Association, etc.).
4. Public editorial advice on writing rebuttal letters (writing guidance, not binding policy).
5. Local manuscript facts supplied by the author.

If a current journal page conflicts with this file, follow the current journal page.

## Implementation implications

- Point-by-point response is the default structure for revision cases; for Taiwan Chinese-language journals the default is a response table.
- Every referee criticism must be answered, justified, or flagged as unresolved. Cross-references are allowed only within the same reviewer's own response, never across mutually blind reviewers.
- A cover letter is adjacent revision-package material: draft it when the user asks for a cover letter or a complete revision package, but do not duplicate the full point-by-point response inside it.
- The skill should copy or preserve reviewer wording supplied by the user unless the user asks for anonymization or summarization.
- Tone, accuracy, and traceability should meet the standard of material that may later be reviewed by editors, reviewers, or public readers (several target journals offer transparent or published peer review).
- Do not overstate source authority: publisher blog advice is useful writing guidance, not journal-specific binding policy.
- Thesis committee responses follow the graduate institute's rules, not journal policy; see `references/thesis-committee-response.md`.
