# 口試委員意見回覆模式

碩士論文計畫書口試或學位論文口試結束後，需要整理「口試委員意見回覆表」（有的所稱「論文修改對照表」「口試委員意見修正說明」）時，使用本模式。本檔依國防醫學院護理學研究所常見做法整理；表格格式、簽核方式與繳交期限以所辦最新規範為準。

## 與期刊退修的差異

| 面向 | 期刊退修 | 口試委員意見回覆 |
|---|---|---|
| 隱私 | 審稿人互盲，每人一份獨立檔案 | 委員意見公開，一份表格所有委員與指導教授都看 |
| 編號 | `E.1`、`R1.1` | `C1.1`（委員一第一條）、`C2.1`；指導教授 `A.1` |
| 決定類型 | 主要／次要修訂關卡 | 不適用；改問「計畫書口試或學位論文口試」與「繳交期限」 |
| 誰簽核 | 編輯 | 指導教授先看，再送各委員確認或簽名（依所辦流程） |
| 修改處標示 | 紅字或底線 | 多數只要求頁碼；若所辦或委員要求，附紅字修改稿 |
| 語言 | 依期刊 | 繁體中文，全形標點；英文詞彙與統計符號半形 |
| 可以不同意嗎 | 可以，附理由 | 可以，但語氣更慎重；先與指導教授確認再寫「經與指導教授討論後……」 |

## 輸入

- 口試委員意見：口試當場筆記、委員的書面意見表、指導教授轉述。若有錄音逐字稿，先請使用者整理成條列。
- 口試類型：計畫書口試（proposal defense）或學位論文口試（thesis defense）。
- 論文修訂後的頁碼或章節（沒有就用佔位符「〔頁碼待補〕」）。
- 所辦要求的表格格式與繳交期限（若使用者不知道，提醒查所辦公告，不要假設）。

## 工作流程

1. 確認口試類型與繳交期限。
2. 把每位委員的意見逐條切分，保留原意；委員口頭意見經整理後要註明「依口試紀錄整理」。
3. 編號：`C1.1`、`C1.2`、`C2.1`；指導教授的意見 `A.1`。若使用者知道委員姓名與職稱，表格用「委員姓名」；不知道就用「委員一」。
4. 每一條分類動作：`ACCEPT_TEXT`、`ACCEPT_ANALYSIS`、`CLARIFY_EXISTING`、`SOFTEN_CLAIM`、`PARTIAL`、`OUT_OF_SCOPE`、`DISAGREE`、`AUTHOR_INPUT_NEEDED`。
5. 工作狀態：`VERIFIED_DONE`（使用者提供修訂後文字或頁碼）、`REPORTED_DONE_UNVERIFIED`、`TODO_TEXT`、`TODO_ANALYSIS`、`TODO_AUTHOR_CONFIRM`。
6. 產出回覆表（欄位：委員／意見／修改內容／頁碼）與論文修改清單。
7. 計畫書口試的意見若涉及研究設計變更（樣本數、收案場域、工具、分析方法），提醒使用者同步檢查 IRB 送審版本是否需要修正案。
8. 不捏造頁碼。修訂後頁碼要等 Word 目錄更新（F9）後再填；沒有就留佔位符。

## 常見的委員意見類型（護理研究所語境）

| 委員意見類型 | 例子 | 預設處理 |
|---|---|---|
| 研究目的與研究問題不對齊 | 「研究目的寫三項，研究問題只有兩項」 | `ACCEPT_TEXT`，修第一章並同步修摘要 |
| 理論框架與工具的連結 | 「Tanner 臨床判斷模型的四個面向如何對應到系統功能？」 | `ACCEPT_TEXT` 或 `ACCEPT_FIGURE`，加對應表 |
| 樣本數與收案 | 「12 位專科護理師的 SUS 分數能代表什麼？」 | `SOFTEN_CLAIM` 加限制；說明 DBR 形成性評估的定位 |
| 質性方法 | 「放聲思考與半結構式訪談的資料如何整合？飽和怎麼判定？」 | `ACCEPT_TEXT`，方法章補分析流程與飽和判準 |
| AI 系統風險 | 「生成式 AI 的幻覺如何控制？病人安全風險？」 | `ACCEPT_TEXT`，補 RAG 檢索來源、人工審核、使用者提示與限制 |
| 倫理 | 「IRB 進度？系統日誌的個資如何去識別化？」 | `AUTHOR_INPUT_NEEDED` 直到有 IRB 案號或進度 |
| 格式 | 「表 3-1 的標題位置」「參考文獻 APA 格式」 | `ACCEPT_TEXT`；APA 交 `apa7-master`；格式依 `bob-shared/journal-formats/ndmc-thesis.md`（完成後） |
| 超出範圍 | 「建議加做多中心驗證」 | `OUT_OF_SCOPE` 寫進「未來研究建議」，並在回覆表註明「列為未來研究方向」 |

## 輸出格式

```text
口試委員意見回覆
- 口試類型：計畫書口試／學位論文口試
- 繳交要求：〔所辦規定的表格與期限；不確定時寫「以所辦公告為準」〕
- 整體就緒狀態：ready_to_submit／draft_with_placeholders／needs_author_input

口試委員意見回覆表
| 編號 | 委員 | 委員意見 | 修改內容 | 頁碼 |
|---|---|---|---|---|

論文修改清單
- C1.1：……
- A.1：……

缺漏資訊
- 〔需要使用者補的頁碼、修訂後文字、IRB 進度等〕
```

表格範本見 `templates/committee-response-table.md`。需要 Word 檔時交 `docx`。

## 語氣範例

```text
感謝委員的建議。原計畫書對放聲思考與半結構式訪談資料的整合方式說明不足，已於第三章第四節補充：兩類資料先分別以主題分析法編碼，再以 Tanner 臨床判斷模型的四個面向作為整合架構進行對照（第 45 至 46 頁）。
```

不同意時：

```text
感謝委員的建議。經與指導教授討論，本研究為設計本位研究的第一輪迭代，樣本以單一醫學中心的專科護理師為對象，多中心驗證超出本階段範圍；已於第五章研究限制與未來研究建議中說明（第 88 頁）。
```
