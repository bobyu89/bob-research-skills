# 預設立場與紅線

本 skill 把退修信（編輯決定信）、審稿意見、作者的修改筆記、既有的回覆草稿或修訂摘要，轉成一套「可稽核」的修訂回覆包：內部／編輯用的總表（master tracker）、每位審稿人各自獨立的逐點回覆信、修訂版 cover letter、修改處標示（底線或紅字）的修改稿摘錄，以及需要時的 Word／Markdown 或 LaTeX 交付檔。另有「口試委員意見回覆」模式，處理碩士論文口試後的委員意見回覆表。

總表是給作者自己或編輯核對用的文件。每一份審稿人回覆都是獨立成文的文件，只含該審稿人的意見與對應回覆。cover letter 是給編輯看的修訂摘要。目標是讓每一條審稿意見都被理解、被回應，並對應到具體的文稿修改、有依據的學術回應，或明確標示的待辦作者行動，同時不把互盲審稿人的內容洩露給另一位審稿人。

## 預設立場

- 先忠實保留每一條審稿意見的原文，再回覆。
- 每一條意見都必須回覆，或明確標示為未解決。交叉引用只能在同一位審稿人的回覆內使用，不能跨審稿人。
- 預設把各審稿人視為互盲。給某位審稿人的檔案不得透露另一位審稿人的意見、編號、建議、身分、回覆文字或相衝突的要求。
- 內部／編輯總表保留完整資訊，用於去重、處理衝突與一致性檢查，並清楚標示「非審稿人可見」。
- 多位審稿人提出同一個問題時，每一位都要得到完整、獨立的回答。不要叫審稿人去看另一位審稿人的回覆。
- 每一則回覆都要對應到文稿證據、修改位置、有依據的不同意見，或 `AUTHOR_INPUT_NEEDED`。
- 「回應動作」「逐項工作狀態」「整包可否送出」三者分開記錄：該做什麼，不等於已經做了。
- 不捏造實驗、分析、引用文獻、行號、圖版、附錄項目、編輯指示、審稿人身分或文稿修改。
- 回覆以精簡、有證據連結為優先，避免冗長的防禦性解釋。
- 英文回覆信、cover letter、內部摘要與作者筆記中，避免把破折號（em dash、en dash）和冒號當成慣用的句間連接符。改用句號分句、逗號、分號、括號，或短標題後換行。審稿人原文引句、標題、公式、識別碼、網址、時間與機器可讀語法的標點保持原樣。
- 中文回覆表與中文說明使用全形標點；統計符號、引用括號與英文詞彙依 APA 第七版慣例用半形。
- 不同意審稿人時，先承認其顧慮，再給出學術或研究範圍上的理由。
- 審稿人誤解文稿時，先考慮是不是文稿的呈現方式造成了誤解。
- 審稿人漏看文中已有的資訊時，把這條意見當成「資訊不夠醒目或不夠清楚」的證據。直接回答問題，在作者支持下改善措辭或位置，並引用修訂後的位置。
- 回覆信要完整，文稿修改要最小。每一處主文新增都先檢視整段，優先考慮取代、壓縮或移到附錄／補充資料，最後才是追加。
- 把回覆信視為可能公開的審查紀錄（部分期刊採透明同儕審查），以專業語氣與可追溯性撰寫。
- cover letter 精簡：指明稿件、感謝編輯與審稿人、摘要主要修訂動作，並指向逐點回覆。
- 修改文稿時，在原稿的備份副本上作業，修改處以紅字或底線標示（依期刊要求）。
- 在回覆信中，回答完一條意見後，若貼上修訂後的文稿文字，一律用斜體。

## 紅線

- 不可略過任何一條審稿意見。
- 不可用改變原意的方式改寫審稿意見。
- 除非作者提供了修改內容，不可宣稱「已修改」。
- 只有回覆草稿或作者口頭說「已完成」而沒有可檢視的修訂成品時，不可標為已驗證。
- 不可捏造行號、圖版、引用文獻、統計結果或附錄項目。
- 不可使用敵意或指責性語言。
- 不可把時間、經費或方便與否當成不做某項要求的主要理由。
- 不可隱藏研究限制。
- 不可把主文寫成預防性的審稿回覆，也不可讓穩健性與調和性的說明把中心證據鏈淹沒。
- 不可預設走申訴信（appeal）路徑。申訴類案例另行處理。
- 仍有佔位符時，不可宣稱 cover letter、回覆信或修改稿已可送出。
- 不可把未完成的文稿修改藏在註解或不會呈現的備註裡。
- 在給審稿人的回覆中不可出現「如審稿人二亦提到」「請見我們對審稿人一的回覆」「另一位審稿人要求」這類跨審稿人語句。
- 給審稿人的檔案不可含另一位審稿人的意見編號或建議。
- 不可把破折號或冒號當成習慣性的句間連接符，能用句號或標題就用句號或標題。
- 不可用「我們已在文中說明」「原稿已經解釋過」「如原稿所清楚描述」這類句子回敬審稿人。文中已有內容，不能免除呈現不清的責任。

## 來源優先順序

依下列順序取用來源：

1. 目標期刊的投稿須知與這封退修信本身。
2. ICMJE 建議、COPE 指引，以及目標期刊所屬出版社的公開同儕審查與修訂流程說明。
3. 出版社或期刊公開的 rebuttal letter 撰寫建議（屬寫作建議，非強制政策）。
4. 作者提供的本稿事實。

期刊政策可能已更新；給最終送出建議前，先查目標期刊官網最新版本，並在回覆中標明查核日期。中文期刊（護理雜誌、護理研究等）的修訂回覆慣例見 `references/taiwan-journal-norms.md`。
