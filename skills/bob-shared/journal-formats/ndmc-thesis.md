# 國防醫學院碩士論文格式慣例（ndmc-thesis）

當 `journal=ndmc-thesis` 或 `task=thesis-chapter` 時使用。整理國防醫學院護理學研究所碩士論文的**常見格式慣例**，供 `bob-writing`、`bob-polishing`、`bob-figure`、`bob-statistics` 在起草或潤飾第一章至第五章時使用。**凡本檔未確定的細節，一律標「以所辦最新規範為準」**；所辦（護理學研究所辦公室）與圖書館的論文格式規範、指導教授的要求，優先於本檔。本檔整理日期 2026-09-06。

## 1. 論文整體結構

常見順序（以所辦最新規範為準）：

1. 封面、書名頁
2. 口試委員審定書（口試通過後）
3. 授權書（國家圖書館、校內）
4. 誌謝（選用）
5. 中文摘要（含關鍵詞）
6. 英文摘要（含 Keywords）
7. 目錄、表目錄、圖目錄
8. 第一章 緒論
9. 第二章 文獻查證（或文獻探討）
10. 第三章 研究方法
11. 第四章 研究結果
12. 第五章 討論（或討論與結論）
13. 參考文獻（中文在前、英文在後，或依所辦）
14. 附錄（IRB 核准函、問卷、訪談大綱、量表授權、系統畫面等）

計畫書口試時通常只有第一章至第三章加參考文獻與附錄，且第三章以未來式撰寫；學位論文口試時第三章改為過去式。

## 2. 各章的常見小節

以下是護理學研究所碩士論文的慣例；實際小節依研究設計與指導教授調整。

### 第一章 緒論
- 第一節 研究背景與動機
- 第二節 研究重要性
- 第三節 研究目的
- 第四節 研究問題（或研究假設）
- 第五節 名詞解釋（概念性定義與操作性定義並列）

### 第二章 文獻查證
- 依主題分節；每節以綜整而非逐篇摘要撰寫；末節常為「研究架構」或「理論框架」（例如 Tanner 臨床判斷模型如何指導本研究）
- 含系統性檢索的文獻回顧交 `scoping-review-master`；概念分析交 `concept-analysis-master`

### 第三章 研究方法
- 研究設計（DBR 研究要有階段圖與迭代結構）
- 研究場域與研究對象（納入排除、取樣、樣本數估算）
- 研究工具（量表來源、信效度、自編問卷的專家效度 CVI；系統本身的描述）
- 資料收集程序（含各迭代的時程）
- 資料分析（量性：統計方法；質性：分析取向與可信賴性）
- 研究倫理考量（IRB、知情同意、個資、弱勢保護、AI 資料流向）

### 第四章 研究結果
- 依研究問題順序或依迭代輪次；每節先描述後推論；圖表依 `表 4-1` 式編號
- DBR：每輪含「設計 → 實施 → 評估 → 修正」；章首附「研究問題 × 迭代 × 資料來源」總表

### 第五章 討論
- 依研究問題或主要發現討論，對照第二章文獻與理論框架
- 結論
- 研究限制（具體說明對結論的影響）
- 建議（護理教育、臨床實務、政策、未來研究）
- 章的名稱與是否把「結論與建議」獨立成第六章，以所辦與指導教授為準

## 3. 排版慣例

| 項目 | 慣例（以所辦最新規範為準） |
|---|---|
| 中文字型 | 標楷體 |
| 英文與數字字型 | Times New Roman |
| 字級 | 正文常見 12 pt；章標題較大；以所辦範本為準 |
| 行距 | 以所辦範本為準（常見固定值或 1.5 倍、2 倍） |
| 頁邊界 | 以所辦範本為準（裝訂邊常較寬） |
| 段落 | 首行縮排兩個中文字元；段落間不空行 |
| 標題階層 | 第一章 → 第一節 → 一、 → （一） → 1. → （1）；階層數以所辦為準 |
| 頁碼 | 前置部分羅馬數字、正文阿拉伯數字，置中或依範本 |
| 標點 | 全形；統計表達式與英文半形；見 `../core/zh-tw-academic-conventions.md` |
| 章起始 | 每章另起新頁 |

## 4. 表格與圖的樣式

### 表格
- 編號：「表 3-1」「表 4-2」（章 - 序號），以所辦為準是否用「表 3-1」或「表 3-1.」。
- 表題在表格**上方**，與編號同行或分行，依範本；表題不加句號。
- 三線表：上橫線、表頭下橫線、下橫線；無直線。
- 表內字型與正文一致或略小；數字對齊小數點。
- 註記在表格下方：「註：」→ 一般註記、特定註記（上標 a、b）、機率註記（*p < .05. **p < .01. ***p < .001.）。
- 跨頁：表頭重複，續頁表題加「（續）」。
- 統計表格的 APA 格式（*M*、*SD*、*n*、*p* 斜體）由 `bob-statistics` 的 `references/spss-output-to-apa-table.md` 處理。

### 圖
- 編號：「圖 3-1」。
- 圖說在圖**下方**：「圖 3-1  ○○○○」（編號與圖說之間兩個半形空格或依範本）。
- 圖內中文字型標楷體或 Noto Sans TC，英文 Times New Roman 或 Arial，依 `bob-figure` 的 `static/fragments/target/thesis-word.md`。
- 解析度與寬度：300 dpi 以上、寬度不超過頁面可用寬度（詳見 bob-figure）。
- 引自他處的圖註明來源與授權。

### 內文引用
- 「如表 4-1 所示」「見圖 3-2」；不用「上表」「下圖」「如下表」。
- 每個圖表都要在正文被引用，且在首次引用後出現。

## 5. Word 操作提醒

- 目錄、表目錄、圖目錄用 Word 的「參照 → 目錄」與「插入標號」功能產生；修改後全選按 **F9** 更新功能變數（或右鍵「更新功能變數 → 更新整個目錄」）。
- 章節標題用「樣式」（標題 1、標題 2……）而不是手動加粗，目錄才能自動產生。
- 圖表標號用「插入標號」並設定「章節編號」，交互參照才會自動更新。
- 頁碼分節：前置部分與正文用「分節符號」分開，各自設定頁碼格式。
- 表格跨頁：表格內容 → 「列」→ 勾選「在各頁頂端以標題列重複」。
- 詳細排版見 `bob-polishing` 的 `references/word-layout.md`。

## 6. 摘要與關鍵詞

- 中文摘要：結構依所辦，常為單段或含「背景、目的、方法、結果、結論」的段落式；字數以所辦為準。
- 英文摘要：與中文一致；字數以所辦為準。
- 關鍵詞：中英各三到六個，一一對應；以所辦為準。
- 摘要策略見 `../core/abstract-evidence-chain.md`。

## 7. 參考文獻

- APA 第七版；中文在前、英文在後（或依所辦）；由 `apa7-master` 產生與稽核。
- 內文引用與清單雙向一致；口試前跑一次一致性檢查。
- 學位論文引用格式、法規引用格式由 `apa7-master` 處理。

## 8. 口試相關慣例

- 計畫書口試（已於 2026-08-12 通過）：第一章至第三章；口試後依委員意見修訂並送 IRB。
- 學位論文口試：全文；口試後依委員意見修訂，取得審定書簽名，再辦理離校程序。
- 口試簡報由 `grad-lecture-to-slides` 或使用者自行製作；本集不處理。
- 口試委員意見的回覆表（意見、回覆、修改處頁碼）可用 `bob-response` 的 `templates/response-letter.md` 改寫成中文版。
