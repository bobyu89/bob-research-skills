# 台灣護理期刊的中文投稿慣例（taiwan-nursing）

## 2. 中文投稿的結構性慣例

### 中英摘要並列
- 中文摘要與英文摘要內容必須一致（結構、數字、結論）；多數期刊要求結構式（背景、目的、方法、結果、結論），段名以期刊為準。
- 中英關鍵詞各三到六個（以期刊為準），一一對應；中文關鍵詞優先採用該刊常用譯名。
- 英文摘要要求的段名與中文對應：背景 Background、目的 Purpose 或 Aim、方法 Methods、結果 Results、結論 Conclusions／Implications for Practice。

### 正文結構
- 研究論文：前言（含研究目的）、文獻查證（或併入前言）、方法、結果、討論、結論與建議、參考文獻。
- 專案類（護理專案、品質改善）：前言、現況分析、問題確立、目的、解決辦法、結果評值、討論與結論；格式與評分由 `nursing-project-reviewer` 處理。
- 個案報告：由 `np-case-report` 處理。
- 實證報告：由 `twna-ebhc-report` 處理。

### APA 中文格式
- 內文引用與參考文獻依台灣護理學會採用的 APA 7 中文格式，由 `apa7-master` 產生。
- 中文文獻與英文文獻分開排列或合併，依期刊。
- 內文引用中文作者用全名（「王大明（2020）」），英文作者用姓氏。

### 標點、字型與數字
- 全形標點；統計表達式半形；數字半形。
- 統計符號斜體規則同 APA 7。
- 字型與字級依期刊範本；多數期刊在接受後由編輯部排版，投稿時只需依範本。
- 圖表：表題在上、圖說在下；表格三線表；圖表編號為「表一」「圖一」（中文數字）或「表 1」「圖 1」，以期刊為準。

### 倫理與聲明
- 方法段須寫 IRB 名稱與編號、知情同意方式。
- 多數台灣期刊要求「利益衝突聲明」與「作者貢獻」，格式以期刊為準。
- 投稿時常需上傳「著作權讓與同意書」或「投稿聲明書」，全體作者簽名。
- 生成式 AI 使用揭露：各刊政策陸續更新，投稿前查核。

## 4. 中文學術寫作的常見審查意見

- 前言太長、缺口不明確；文獻查證只是摘要文獻沒有綜整
- 研究目的與研究問題、研究工具、統計方法不對應
- 方法段缺樣本數估算、量表信效度、IRB 編號
- 結果只列表格沒有文字說明，或文字重複表格所有數字
- 討論沒有與文獻對話；限制與建議空泛
- 中英摘要不一致；英文摘要文法錯誤
- 全形半形混用；大陸用語；術語不一致
- 參考文獻格式錯誤或內文與清單不對應

## 5. 與英文期刊的差異提醒

- 中文期刊多數不接受「已在英文期刊發表」的同一研究；若計畫中英各投，先確認兩刊政策並避免一稿多投。
- 碩士論文改寫投稿時，共同作者與作者順序依所辦與指導教授慣例；通訊作者通常為指導教授。
- 中文期刊的審查週期與英文期刊不同，投稿前可查該刊近期文章的收稿與接受日期。
