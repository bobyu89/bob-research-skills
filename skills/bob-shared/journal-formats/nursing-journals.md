# 護理與醫學教育期刊的投稿前必查清單（nursing-journals）

當 `journal=nursing` 時使用。涵蓋使用者常投的英文護理、護理教育與醫學教育期刊。此檔案**不寫死任何字數、圖表數或參考文獻數**；每一本期刊的規定會變，投稿前一律到官網確認，並把查核日期填入清單。以下「特色」欄是各刊**長期穩定的結構性特徵**，仍以官網為準（本檔整理日期 2026-09-06）。

## 2. 投稿前必查清單（每本期刊都要跑一次）

到官網的 Author Guidelines 逐項確認並記錄：

### 文章類型與限制
- [ ] 文章類型名稱（Original Research、Review、Protocol、Discursive paper 等）
- [ ] 正文字數上限與計算範圍（是否含摘要、參考文獻、表格）
- [ ] 摘要字數上限與是否結構式；段落名稱與順序
- [ ] 關鍵詞數量與來源（MeSH、CINAHL Headings）
- [ ] 圖表數量上限；表格是否算入字數
- [ ] 參考文獻數量上限（部分期刊有）
- [ ] 補充資料的限制

### 稿件結構
- [ ] 是否要求 Impact statement、What is already known / What this paper adds、Highlights、Tweetable abstract、Practice points 等額外段落
- [ ] 是否要求 Patient and Public Involvement 段
- [ ] Discussion 是否要求獨立的 Limitations、Implications for practice / education / policy、Conclusion
- [ ] 質性研究是否要求 Rigour / Trustworthiness 小節
- [ ] 混合方法是否要求 Integration 小節

### 格式
- [ ] 參考文獻格式（APA 7、Vancouver、期刊自訂）與範例
- [ ] 標題頁內容；盲審時本文需移除的資訊
- [ ] 圖表放在正文、文末或分檔上傳；圖檔格式與解析度
- [ ] 表格格式（三線表、註記位置）
- [ ] 統計報告格式（是否指定 APA、效果量與 CI 要求）
- [ ] 英文拼法（British 或 American）；期刊是否強制其一
- [ ] 檔案格式（.docx、PDF）；是否要求 LaTeX 以外

### 聲明與附件
- [ ] 必要聲明清單（見 `generic-health.md` 第 4 節）
- [ ] 報告準則檢核表（CONSORT、STROBE、COREQ、SRQR、PRISMA-ScR 等）是否必附
- [ ] 封面信要求
- [ ] 作者貢獻格式（CRediT）
- [ ] AI 使用揭露政策與放置位置
- [ ] 資料可用性聲明的格式
- [ ] 臨床試驗登錄要求（含教育介入是否視為試驗）
- [ ] 倫理審查聲明的格式（是否要求編號）

### 流程
- [ ] 投稿系統（Editorial Manager、ScholarOne、Wiley Research Exchange 等）與帳號
- [ ] 推薦或迴避審查委員
- [ ] 開放取用選項與 APC；折扣或豁免
- [ ] 預印本政策
- [ ] 同一研究的多篇文章（例如計畫書已發表）是否須揭露
- [ ] 平均審查時間（官網或近期文章的 received / accepted 日期）

## 3. 各期刊常見的結構性特徵說明

以下描述是**特徵**而非數字，且可能變動：

- **JAN 與 Wiley 系列（JAN、JCN、Nursing Open）** 慣例上要求較長的結構式摘要，並有專門的 Impact 或 Contribution 段，用來回答「這篇對病人、實務或政策的影響」。撰寫時把它當作討論的 Implications 的濃縮，不要重複摘要 Conclusion。
- **IJNS** 對方法學的要求接近醫學期刊：樣本數估算、效果量、遺漏值處理、報告準則都會被審。What is already known / What this paper adds 段常以條列呈現，每條一句。
- **NET 與 NEP（Elsevier 護理教育系列）** 重視教育介入的可複製性；Highlights 是三到五條簡短陳述，各自獨立可讀。教育研究若無隨機分派，說清楚為什麼，並用 TREND 或 STROBE。
- **JNR** 為台灣護理學會的英文期刊，對台灣作者友善；Implications for Practice 是摘要與正文的固定段落；引用格式以官網為準。
- **CIN** 收系統開發與評估類論文，適合使用者的 RAG 學習系統若以系統描述與可用性評估為主軸；系統的技術描述要足以讓資訊背景的讀者理解，但主軸仍是護理或教育的問題。
- **BMC 系列** 的 Declarations 段落名稱固定且順序固定（Ethics approval and consent to participate、Consent for publication、Availability of data and materials、Competing interests、Funding、Authors' contributions、Acknowledgements），漏一項系統會退回。
- **Medical Teacher 與 AHSE** 屬醫學教育，理論框架的運用會被嚴格審視；DBR 論文在這類期刊要清楚交代設計原則與理論貢獻。

## 4. 期刊選擇的判斷（供 bob-writing 的 submission-package 使用）

- 先讀 Aims and scope 與近兩年同主題的三到五篇文章，確認研究設計與寫法在該刊常見。
- 系統開發與可用性為主 → CIN、JMIR 系列（見 `jmir.md`）
- 教育介入與學習成效為主 → NET、NEP、BMC Med Educ、Medical Teacher
- 理論框架與方法學貢獻為主 → JAN、IJNS、AHSE
- 台灣脈絡、希望較快審查 → JNR、台灣中文期刊（見 `taiwan-nursing.md`）
- 不做影響係數的臆測；引用 JCR 或 Scopus 的數字時註明年份與來源。

## 5. 常見退稿原因（護理教育與數位健康研究）

- 教育介入描述不足，讀者無法複製（缺 TIDieR 項目）
- 只有滿意度或可用性，沒有學習成效或行為改變的證據，且未在限制中誠實說明
- 自編問卷沒有信效度證據
- 質性部分沒有可信賴性策略或 COREQ 項目
- 系統論文把技術細節寫成主角，護理或教育問題退居其次
- 單一機構、便利取樣、無對照組卻在結論中推廣
- 未附報告準則檢核表
