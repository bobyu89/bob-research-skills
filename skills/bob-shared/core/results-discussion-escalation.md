# 結果的主張推進與討論的綜合（Results–Discussion escalation）

供 `bob-writing`、`bob-polishing`、`bob-reviewer` 起草、重組、潤飾或審查健康科學與護理研究的結果（Results）與討論（Discussion），或碩士論文第四章與第五章時使用。此檔案是**寫作指引，不是期刊官方規定**；目標期刊的作者須知、報告準則（CONSORT、STROBE、COREQ、PRISMA-ScR 等對結果與討論的必要項目）與論文本身的證據永遠優先。討論段的語言校準另見 `discussion-argument-language.md`；主文精簡與附錄分配見 `main-text-discipline.md`。

## 結果與討論的分工

- **結果：** 透過證據鏈確立並推進論文的主張。結果可以包含比較、前後測、次群體、迭代間的變化、失敗分析、直接受證據約束的詮釋，以及局部推論。
- **討論：** 把數個已確立的主張綜合成更高層次的理解，把這個理解對照先前研究與理論框架，說明它的重要性，並限定它的含意。

不要機械地執行「結果只有事實、討論才有詮釋」。有效的邊界是**局部詮釋**與**綜合詮釋**：直接解決剛剛報告的那個分析的解釋留在結果；更廣的理論、文獻整合、一般含意與延伸推測移到討論。

量性論文的慣例較嚴格，結果段的詮釋要非常節制；質性論文與 DBR 論文的結果段本來就含有詮釋（主題的命名與說明、每輪迭代的設計決策理由），這是設計的一部分，不要為了「客觀」硬把它拔掉。

## 把結果寫成主張推進

讓每一個結果小節回答一個研究問題、確立一個新主張。當證據支持時，偏好帶有結論的標題，而不是流程式的分析標籤（「表 4-3 之分析」是標籤；「系統可用性達可接受等級且與使用頻率相關」是主張）。碩士論文若所辦要求依研究問題編號命名小節，依規定，但小節首句仍應直接給出主張。

安排相鄰小節，讓每一個結果引出下一個問題：

`觀察 → 未解問題 → 針對性分析或下一輪迭代 → 比較或擾動 → 局部詮釋 → 更強的主張 → 下一個問題`

在論文層級，偏好逐步推進的弧線，例如：

`現象或需求 → 來源或設計決策 → 必要條件或機制 → 分解 → 邊界或穩健性`

不要用同一主張的重複展示來代替推進。兩個小節可以共用資料、條件或方法；只有當它們收斂到同一個推論結論時才算重複。

## 依研究設計選擇證據鏈原型

依推論功能組織結果，不要依「系統描述 → 問卷 → 訪談」這種例行清單。選擇或組合符合主張的原型：

### 迭代發現循環（DBR、行動研究、品質改善）

當證據改變了下一步該測什麼時使用：

`需求分析或初始設計 → 第一輪實施與評估 → 分析證據 → 修正設計原則 → 下一輪 → 設計原則與成效的驗證`

結果應保留這個認識論的循環，但不能變成按時間排列的研究日誌。只保留改變了主張或下一個問題的迭代。V1 到 V7 的每一版不一定都要一個小節；把只改了介面顏色的版本合併，把改變了學習流程的版本獨立。

### 核心成效與驗證範圍（介入研究、量表發展）

當論文確立一個核心成效，然後問它是否可靠、安全、可推廣或被干擾時使用：

`確立核心成效 → 在關鍵情境驗證 → 檢驗偏誤或安全 → 排除主要替代解釋 → 界定限制`

把次群體、劑量、使用頻率、學習者背景等分析當作主故事的驗證範圍，用來回答「同一個核心成效在重要條件下是否存活」。不要把每個檢查都呈現成不相關的第二個發現。

### 能力階梯（系統或模型研究）

當系統或模型支持逐步更強的主張時使用：

`量化表現 → 對資料特性的穩健性 → 更強的比較對象 → 可解釋性 → 更廣的遷移能力`

每一階都必須證成更強的推論。同一推論層級再多一個資料集或再多一個基準，不會自動成為新的一階。

### 主題深化（質性研究）

`描述參與者與脈絡 → 呈現主題與次主題 → 以引文支撐每個主題 → 主題之間的關係 → 反例或分歧的經驗`

主題不是分類標籤的清單；每一個主題要說明它回答了研究問題的哪一部分，並以「厚描述」與引文支撐。反例與少數經驗要寫，它們常是討論中最有價值的材料。

### 分後合（混合方法）

`量性結果 → 質性結果 → 整合（joint display、meta-inference）`

或依研究問題交錯呈現。整合段必須明確說明兩種資料是「一致（convergence）」「互補（complementarity）」還是「分歧（divergence）」，並解釋分歧。

跨原型最常見的功能鏈是：

`確立現象 → 壓力測試 → 排除替代解釋 → 擴大 → 詮釋 → 限定`

不是每篇論文都需要每個動作。保留對核心主張足夠的最短鏈。

## 避免同層級的重複

後面的小節可以重用前面的基準、對照或參照比較，但不能把同一個比較與同一個結論當作新結果呈現。把重用的條件當作**必要的比較對象**，而不是後面那個小節的中心。

問後面的分析加了什麼更深的區辨：

- 內容存在 vs. 正確對應（系統有回答 vs. 回答符合臨床指引）
- 關聯 vs. 必要性
- 表面表現 vs. 穩健性
- 表面的增益 vs. 資料、時間或練習量的干擾
- 一個情境 vs. 推廣的邊界

讓新的擾動、反證、更強的比較對象或邊界測試成為小節的決定性證據。如果相鄰兩個小節都可以摘要為「X 有幫助」，就合併、壓縮重複的比較、或把較弱的展示移到附錄。

## 每一個證據單位以推論收尾

在一組連貫的測量之後，陳述證據確立了什麼；不要停在一串數字。推論不能比評估的條件更廣。

報告失敗、反轉、異常的趨勢、表現弱的次群體與取捨，當它們實質定義了主張在哪裡成立、削弱或失效。不要把會改變結論的邊界藏在附錄。

當穩健性分析確立了必要條件、排除了主要替代解釋、揭露了失敗邊界、或產生獨立的科學推論時，放在主文。當它只是再次保證同一結論在另一個估計方式、門檻或次要規格下存活時，移到附錄。

## 局部詮釋的閘門

結果段可以用「顯示」「指出」「可能是因為」「推測」這類校準過的語言，只有當以下條件全部成立：

1. 詮釋回答的是緊接在前的結果所引出的問題
2. 支持它的證據在當前小節可見
3. 不確定性與替代解釋保持明確
4. 這段話是在關閉局部的證據單位，而不是開啟廣泛的領域討論

如果需要好幾句話來調和理論、先前文獻或競爭的機制，就在結果段陳述有邊界的局部推論，把延伸的綜合移到討論。

## 把討論寫成綜合而不是重演

使用這個動作順序：

`簡短的核心發現錨點 → 跨結果的綜合 → 對照先前研究或理論框架 → 重要性 → 邊界條件與限制 → 實務、教育或研究含意`

開頭用一個壓縮的判斷重新定義論文的核心發現。簡短的回顧，偶爾加一個不可或缺的錨點數字，是可接受的。然後立刻進入機制或概念詮釋、重要性、限制與含意。不要重演已在結果中用來展示主張的完整比較、效果量、統計檢定與推論。

區分：

- **必要的回顧／錨點：** 「結果確立了 X；合在一起，X 意味著 Y」
- **多餘的重演：** 結果與討論都重播「A 對 B → 效果 → 檢定 → 因此 X」

護理與健康科學期刊的討論通常還要求明確的 **Implications for practice / education / policy** 與 **Limitations** 段（有時是獨立標題）。理論框架（例如 Tanner 模型）在討論中的角色是「解釋為什麼會這樣」與「框架本身在這個情境是否得到支持或需要修正」，不是把結果重新套進框架的四個階段再說一遍。

部分期刊用 Conclusion 取代或附加在 Discussion 之後。以目標期刊的作者須知或所辦規範為準。

## 碩士論文第四章與第五章的慣例

- 第四章「研究結果」通常依研究問題順序組織；每個研究問題一節，每節先描述統計後推論統計（量性），或先參與者描述後主題（質性）。DBR 論文可依迭代輪次組織，但需在章首以一張總表對應「研究問題 × 迭代輪次 × 資料來源」。
- 表格編號為「表 4-1」式，圖為「圖 4-1」式；表題在上、圖說在下；樣式見 `../journal-formats/ndmc-thesis.md`。
- 第五章通常包含：討論（依研究問題或主要發現）、結論、研究限制、建議（實務、教育、政策、未來研究）。討論的每一小節要回應第四章的對應小節與第二章的文獻。
- 口試委員最常挑的問題：結果與討論之間沒有新增的綜合、討論只是把結果再說一遍加幾篇文獻；限制寫成通用清單而沒有說明對結論的影響；建議與發現無關。

## 主張推進審核表

對每一個結果小節記錄：

| 審核欄位 | 問題 |
|---|---|
| 研究問題 | 這個小節回答哪一個未解問題？ |
| 新主張 | 這裡開始可以支持哪一個先前無法支持的命題？ |
| 證據鏈角色 | 確立、壓力測試、區辨、擴大、詮釋、還是限定？ |
| 決定性證據 | 哪個比較、擾動、迭代或分析確立了它？ |
| 推論增益 | 若移除這個小節，會消失哪一個獨立推論？ |
| 下一個問題 | 哪個不確定性自然引出下一個小節？ |

當相鄰小節的「新主張」或「推論增益」實質相同時標記出來。合併、壓縮，或把較弱的重複移到附錄。

在定稿討論之前，把每一個重複出現的主張對應到一個不同的修辭功能：`錨點`、`綜合`、`對照`、`限定`、`延伸`。刪除任何只是重演結果證據的重複。
