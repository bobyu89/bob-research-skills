# 讀者工作流（Reader workflow）

供 `bob-polishing` 與 `bob-writing` 共用的核心參考；`bob-reviewer` 在綜合段落也會引用。此檔案是共享定義，不是獨立工作流。

## 讀者的提問順序

多數學術論文的讀者（審查委員、期刊編輯、口試委員、臨床同儕）在閱讀時會依照一個穩定的順序自問：

1. **相關性（Relevance）**：這篇跟我有關嗎？
2. **新穎性（Novelty）**：這篇新在哪裡？
3. **可信度（Trust）**：我相信這個結果嗎？
4. **可用性（Reuse）**：我能不能拿來用？
5. **意義與邊界（Meaning）**：這代表什麼？適用範圍到哪裡？

不論任務是從零起草還是潤飾既有文字，論文都應該幫助讀者**依這個順序**回答上述問題。

## 對護理／健康科學論文的具體含意

- 把新穎性（第 2 問）埋在方法細節（服務第 3 問）後面的草稿，會在第一段就失去讀者。臨床讀者尤其沒有耐心等到第三頁才知道「這個介入到底改變了什麼」。
- 只改善句子流暢度、卻沒有把相關性（第 1 問）提早的潤飾，對跨領域讀者仍然無效。護理期刊的讀者橫跨臨床、教育、管理與資訊，摘要與前言第一段必須讓不同背景的人都能判斷「這跟我的病人、學生或系統有沒有關係」。
- 「邊界在哪裡」（第 5 問）最常被略過。起草與潤飾都應該把邊界寫出來，而不是用模糊語言帶過。例如：單一機構、便利取樣、自陳式問卷、短期追蹤、原型系統而非正式上線，這些都是讀者要知道的邊界。
- 「可用性」（第 4 問）在實務導向的期刊格外重要。讀者會問：介入方案的細節夠不夠讓我複製？量表可不可以取得？系統的技術門檻是什麼？

## 不同讀者的重心

| 讀者 | 最在意的問題 | 對寫作的要求 |
|---|---|---|
| 期刊編輯（初審） | 1、2 | 摘要與封面信要在一分鐘內講清楚相關性與新意 |
| 審查委員 | 3、5 | 方法透明、統計正確、限制誠實、結論不超出證據 |
| 口試委員（碩士論文） | 2、3、5 | 研究問題與方法的對應、理論框架的落實、結果與討論的一致性 |
| 臨床或教育實務者 | 1、4 | 介入內容可複製、工具可取得、效益與成本說得清楚 |
| 政策或管理者 | 1、5 | 可推廣性、資源需求、風險 |

## 使用方式

- 起草時：先為每一節寫下它主要回答讀者的哪一問，再決定段落順序。
- 潤飾時：逐段標記它服務的問題編號；連續多段都只服務第 3 問而第 2 問尚未出現，就是結構問題，不是句子問題。
- 審稿時：檢查五個問題是否都能在論文中找到明確答案，並指出缺少的那一個。
