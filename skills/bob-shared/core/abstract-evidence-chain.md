# 摘要的證據鏈（Abstract evidence chain）

供 `bob-writing`、`bob-polishing`、`bob-reviewer` 起草、重組、潤飾或審查健康科學與護理研究的摘要時使用。同時支援**結構式摘要**（多數護理與醫學教育期刊、JMIR 系列、台灣護理期刊）與**非結構式摘要**（部分期刊、會議、碩士論文）。此檔案是**寫作指引，不是期刊官方規定**；摘要的字數、段落標題與是否允許縮寫，一律以目標期刊官網為準。

## 把摘要當作最短的證據鏈

不要把摘要寫成壓縮版前言或章節目錄。把整篇論文壓縮成能讓核心發現「可理解、可信、有後果」的最短鏈：

`精確的問題或缺口 → 本研究做了什麼來解決它 → 主要發現 → 決定性的支持或邊界 → 這個發現確立了什麼 → 為什麼重要`

在前言的問題、結果的證據鏈與討論的綜合都穩定之後，才寫摘要。摘要應揭露論文的論證，而不是研究過程的時間順序。

## 結構式摘要的段落任務

各期刊的段落標題不同（常見組合：Background / Aim(s) / Design / Methods / Results / Conclusion(s)；或 Objective / Methods / Results / Conclusions；JMIR 另有 Background / Objective / Methods / Results / Conclusions 五段），但每一段的任務是穩定的：

| 段落 | 任務 | 一到兩句就夠的內容 | 常見失誤 |
|---|---|---|---|
| **Background** | 已知現象與精確缺口 | 一句已知、一句未知 | 講領域重要性講了三句 |
| **Aim / Objective** | 研究目的，與正文的研究目的字句一致 | 「本研究旨在……」一句 | 目的與結論對不上 |
| **Design** | 研究設計的名稱 | 例如「設計本位研究，含兩輪迭代」「橫斷式相關性研究」「描述性質性研究」 | 把 Design 與 Methods 混寫 |
| **Methods** | 場域、參與者與人數、介入或工具、主要測量、分析方法、資料收集期間 | 每項一個片語 | 列出所有次要測量 |
| **Results** | 主要發現，含必要的數字 | 主要結果的效果量與信賴區間或 p 值；質性研究給主題數與主題名 | 每個結果都給一句；只給 p 值不給效果量 |
| **Conclusion** | 發現的意義與邊界，不重複結果 | 一句意義、一句實務或研究含意 | 「需要更多研究」當結尾 |

期刊若要求 **Impact statement**、**Patient or Public Contribution**、**Trial registration**、**Keywords** 等額外欄位，依期刊；缺少時標 `AUTHOR_INPUT_NEEDED`，不要代填。

## 非結構式摘要的動作順序

單段摘要的預設動作順序：

1. 已知現象或重要問題（一句）
2. 精確的未解問題（一句）
3. 用來回答它的研究設計或概念性動作
4. 主要發現
5. 一到兩個關鍵的支持發現或邊界
6. 概念、實務或領域層級的含意

快速進入本研究。只花剛好足夠的背景讓缺口可理解。重心必須是「我們發現 X」，而不是「我們評估了很多東西」或「我們提出一個框架」。

這個順序是修辭指引，不是六句話的規定。依目標期刊的字數上限合併動作。

## 把缺口寫得又準又短

用一句話（最多兩句）把已知現象接到精確的未知。偏好：

`X 越來越常被使用或觀察到，但 Y 是否、為何或在什麼條件下成立仍不清楚。`

不要在摘要裡證明整個領域很重要、摘要好幾代的先前研究、或重演前言漏斗。當論文處理的是精確的來源、條件、機制或邊界時，避免「既有方法仍面臨挑戰」這類籠統缺口。

## 只保留能解釋答案的方法邏輯

方法只描述到足以理解「為什麼這個設計能回答問題」的程度。當它是核心時，包含：

- 辨識主張的對照或比較（例如前後測、對照組、迭代輪次）
- 檢驗機制的介入、擾動或分解
- 判斷推廣性所需的範圍（場域、人數、期間）
- 質性研究的取樣策略與分析取向
- 主要的測量工具與其名稱（SUS、自編問卷、系統日誌）

省略技術細節（模型名稱與參數、伺服器配置）、例行的資料切分、實作模組，除非其中之一定義了發現或它的邊界。摘要不是方法摘要。

## 選一個主要主張

選一個核心主張，最多加一到兩個支持主張。其餘結果壓縮成證據類別或省略。

| 角色 | 摘要中的決定 |
|---|---|
| 主要主張 | 明確陳述，給最多空間 |
| 決定性支持 | 讓主要主張可信所需時保留 |
| 邊界 | 會實質改變主張讀法時保留 |
| 範圍憑證 | 只有當廣度本身支持推論時才簡短提及 |
| 次要分析 | 省略或留給正文與附錄 |

不要給每一個結果小節一句話。研究規模是可信度的線索，不是主角：只有當範圍對理解推廣性或信心是必要的時候才用「在……個情境中」。

## 數字只在必要時出現

數字只在它執行以下功能之一時才放進摘要：

- 定義主要發現的強度或門檻（例如 SUS 平均分數與其對應的可接受等級）
- 本身就是論文的主要結果（例如工具的信度係數、預測模型的 AUC）
- 讓一個決定性比較可被解讀（效果量與 95% CI）
- 確立一個質性措辭會模糊掉的邊界

量性研究的 Results 段通常需要至少一組主要結果的數字，且格式依 APA 7 統計格式（見 `bob-statistics`）。質性研究的 Results 段給參與者人數與主題，不需要統計數字。

若有數個數字競爭空間，保留最能改變讀者對核心主張理解的那一個。不要只因為有就報告樣本數、所有量表分數與多個效果量。

## 以意義收尾而不是自評

用最後一句說明發現改變了什麼、促成了什麼、連結了什麼、或讓什麼變得可預測。偏好有邊界的實務或領域層級意義，而不是自我評價：

- 某個設計原則變得可辨識
- 某個介入或工具可以用在先前無法觸及的情境（例如自主練習、夜班學習）
- 某個臨床或教育決策獲得量化或機制的依據
- 某個理論框架在新的族群或情境得到支持或修正

不要用「本系統表現優異」「需要更多研究」或超出測試範圍的宏大承諾收尾。

## 摘要與正文的對齊

把四個部分當作同一核心主張的不同壓縮：

- **摘要：** 最短的主張、證據、意義鏈
- **前言：** 為什麼精確的問題必須被問
- **結果：** 回答它的完整證據鏈
- **討論：** 答案共同的意義

摘要的每一個主張都要對應到可見的結果證據。最後的含意必須符合討論的綜合且不超出其邊界。不要在摘要引入正文沒有確立的主張、機制或應用。碩士論文的中文摘要與英文摘要也必須是同一份內容的兩種語言，不能各寫各的。

## 中英摘要並列的規則

台灣護理期刊與碩士論文通常要求中英摘要並列。規則：

- 內容一致：結構、主張、數字、結論完全對應；英文不是中文的「另一版本」。
- 數字格式一致：中文摘要的統計數字仍用半形數字與符號，小數點與 p 值格式與英文相同。
- 專有名詞依術語帳（`terminology-ledger.md`）的中英對照，首次出現時中文摘要可用「中文（英文, 縮寫）」，英文摘要則展開一次。
- 關鍵詞：中英各三到六個，兩邊一一對應，優先使用 MeSH 或 CINAHL Subject Headings 的詞；台灣期刊的中文關鍵詞以該刊慣用譯名為準。
- 字數：中英各有上限，且經常不同，以期刊官網或所辦規範為準。
- 標點：中文摘要用全形標點，統計表達式內用半形；英文摘要全部半形。

## 摘要審核表

在潤飾句子之前先建這張表：

| 摘要動作 | 內容 | 正文支持 | 保留測試 |
|---|---|---|---|
| 缺口 | 精確的未解問題 | 前言 | 能用一句尖銳的話說出來嗎？ |
| 設計 | 能回答問題的邏輯 | 方法／結果 | 它解釋了為什麼問題可以被回答嗎？ |
| 主要發現 | 一個核心主張 | 結果 | 這是論文真正的進展嗎？ |
| 支持／邊界 | 一到兩個決定性發現 | 結果 | 每一個都實質強化或限定主張嗎？ |
| 意義 | 發現改變了什麼 | 討論 | 重要且與範圍相稱嗎？ |

然後刪除或壓縮：

- 標題已經暗示的背景
- 不解釋辨識或推論邏輯的實作細節
- 用實驗清單代替發現
- 只為了完整而放進來的次要結果
- 不定義、不支持、不限定主要主張的數字
- 只說方法表現良好的結尾句
- 結構式摘要中 Conclusion 段重複 Results 段的數字

把所有方法與工具名稱遮起來讀一次摘要。如果核心發現與它為什麼重要已經看不清楚，摘要就是圍繞實作而不是洞見組織的。
