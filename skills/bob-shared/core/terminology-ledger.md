# 術語帳（Terminology Ledger）

一篇論文裡，一件事只能有一個名字。同一個方法、模型、系統、資料集、量表、變項、指標或概念，不能在不同章節之間改換名稱、拼法、大小寫或中譯。審查委員會把術語不一致讀成粗心；一個在章節之間變來變去的術語，會迫使讀者重新學一次。

中文論文與中英並列的稿件另有一層：**中文定名與英文原文必須一對一**。「臨床推理」不能在第二章變成「臨床推論」，「專科護理師」不能在第四章變成「專師」而沒有先定義。

在起草或潤飾之前**先**建立術語帳，之後把它當作整份工作的唯一標準。沒有寫下來的標準，是無法檢查一致性的。

## 1. 初次接觸時建立術語帳

第一次收到稿件、草稿或筆記時，先把所有反覆出現的領域術語抽出來，再動任何文字：

- 方法、模型、系統、演算法、模組、框架（例如 RAG、Tanner 臨床判斷模型、LQQOPERA）
- 資料集、題庫、場域、樣本、參與者群體
- 量表與工具（SUS、自編問卷），含版本與語言版
- 變項名稱、指標、單位、統計符號、數學記號
- 縮寫與首字母縮略詞，各附完整形式
- 論文定義或反覆依賴的關鍵概念（例如「臨床推理」「臨床判斷」「臨床決策」三者是否同義，要先定）
- 系統或介入的版本標籤（V1 到 V7、第一輪到第三輪迭代）

每個術語記錄：標準形式、首次使用時的展開、來源中已出現的變體、中文定名。

## 2. 向使用者呈現術語帳

在第一次輸出之前或同時，給一張精簡表：

| 標準術語（英） | 中文定名 | 首次使用時的定義 | 來源中出現的變體 | 決定 |
|---|---|---|---|---|
| retrieval-augmented generation (RAG) | 檢索增強生成 | retrieval-augmented generation (RAG) ／ 檢索增強生成（RAG） | 「檢索增強技術」「RAG 技術」「檢索式生成」 | 首次展開一次，之後用 RAG |
| nurse practitioner (NP) | 專科護理師 | nurse practitioner (NP) ／ 專科護理師（NP） | 「專師」「NP 學員」「專科護理師學生」 | 正文用「專科護理師」；指學生時用「專科護理師組研究生」 |
| System Usability Scale (SUS) | 系統可用性量表 | System Usability Scale (SUS; Brooke, 1996) | 「系統易用性量表」「可用性量表」 | 統一「系統可用性量表」 |
| clinical reasoning | 臨床推理 | 依論文第二章定義 | 「臨床推論」「臨床思考」 | 統一「臨床推理」；「臨床判斷」保留給 Tanner 模型的專有名詞 |
| think-aloud | 放聲思考 | think-aloud protocol ／ 放聲思考法 | 「有聲思考」「出聲思考」 | 統一「放聲思考」 |

明確標出每一個衝突：同一個概念用了不同名字，或同一個名字被用在兩個不同概念上。只有在決定真的模稜兩可或涉及領域敏感時才請使用者確認；否則採用來源中最常出現的形式，並說明這個選擇。

### 中文定名的規則

- 一個英文術語只對應一個中文定名；一個中文定名只對應一個英文術語。
- 首次出現時中英並列：中文在前、英文與縮寫在全形括號內，例如「系統可用性量表（System Usability Scale, SUS）」。之後只用中文定名或縮寫，二擇一並全文一致。
- 若期刊或所辦規定英文在前，依規定；但全文只能用一種順序。
- 專有名詞的中譯優先採用：（1）台灣護理學會或國家教育研究院雙語詞彙的譯法；（2）台灣既有中文文獻的多數用法；（3）使用者的計畫書已採用的譯法。不要自創譯名。
- 大陸用語一律換成台灣用語，對照表見 `zh-tw-academic-conventions.md`。

## 3. 鎖定並執行

術語帳一旦定案，整份工作都固定：

- 所有輸出只用標準形式。不要為了文字變化而引入同義詞；在學術寫作裡，術語一致性優先於詞彙多樣性。
- 每個縮寫只在首次使用時定義一次，之後用短形式。摘要與正文各算一次「首次」；表格與圖說若能獨立閱讀，也各自定義一次。
- 單位、符號、記號在每一節都完全相同。
- 起草或潤飾後面的章節時，參照從前面章節建立的術語帳，不要逐一重新決定。
- 使用者若之後改名，整份稿件的每一處都要改，不只是目前這一段，並更新術語帳。
- 中英對照表可以直接放進碩士論文的附錄或期刊稿件的補充資料，作為讀者的參考。

## 4. 不要發明術語

不要為作者的方法、模組、系統或概念自創新名稱或新中譯。若術語缺漏、未定義、或使用不一致到無法從來源判斷，請問使用者或標記出來。絕對不要用猜的名字填補空缺。

## 5. 與其他工具的關係

- 事前預防用本檔；事後偵測用 `consistency-sweep.md` 與 `scripts/check_consistency.py`（可用 `--term-group` 把術語帳的變體餵進去）。
- 參考文獻中的量表名稱、期刊名稱由 `apa7-master` 處理，但內文的中文定名以本術語帳為準。
- 圖表中的標籤（`bob-figure`）也要對照術語帳。
