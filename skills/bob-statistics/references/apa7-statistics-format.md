## 一、統計符號與斜體

- 拉丁字母的統計符號一律**斜體**：*n*、*N*、*M*、*SD*、*SE*、*Mdn*、*t*、*F*、*p*、*r*、*R*²、*d*、*g*、*z*、*df*、*B*、*b*、*OR*、*RR*、*HR*。
- 希臘字母**不斜體**：α、β、χ²、η²、ηp²、ω²、Δ、Σ。
- 下標與上標不斜體：*R*² 的 2、ηp² 的 p、*t*(38) 的括號與數字都不斜體。
- 縮寫詞不斜體：ANOVA、ANCOVA、MANOVA、GEE、CI、SEM、CFA、EFA、KMO、RMSEA、CFI、TLI、SRMR、AIC、BIC。
- 運算符號前後各留一個半形空格：*M* = 3.42，*p* < .001，*t*(38) = 2.14。
- 自由度緊接在檢定符號後的括號內，括號與符號之間不留空格：*t*(38)、*F*(2, 117)、χ²(3, *N* = 120)。
- 百分比：數字後直接接 %，不留空格（45.2%）；表格欄名可用「%」或「百分比」。
- 負號用減號或半形連字號皆可，但整篇要一致；不用全形「－」在英文句中。

## 二、小數位與前導零

| 統計量 | 小數位 | 前導零 | 範例 |
|---|---|---|---|
| 平均數、標準差、中位數 | 2 位（原始量表通常 2 位） | 有 | *M* = 3.42，*SD* = 0.87 |
| 百分比 | 1 位（或整數） | 有 | 45.2% |
| *t*、*F*、χ²、*z* | 2 位 | 有 | *t*(38) = 2.14 |
| *p* | 2 或 3 位 | **無** | *p* = .03，*p* = .012 |
| *r*、*R*²、β（標準化）、α、CVI | 2 位 | **無** | *r* = .46，α = .89 |
| Cohen's *d*、Hedges' *g* | 2 位 | 有 | *d* = 0.52 |
| η²、ηp²、ω² | 2 位 | **無** | ηp² = .12 |
| OR、RR、HR、*B*（非標準化） | 2 位 | 有 | *OR* = 1.84 |
| 95% CI | 與對應統計量相同 | 依統計量 | 95% CI [0.21, 0.83] |
| 自由度 | 整數；Welch 或 Greenhouse–Geisser 校正可用小數 | — | *t*(36.4) = 2.10 |
| *n*、*N* | 整數 | — | *N* = 120 |

前導零規則：**值不可能超過 1 的統計量不寫前導零**（*p*、*r*、α、β 標準化係數、η²、CVI、R²）。可能超過 1 的（*d*、*M*、*SD*、*t*、*OR*）要寫前導零。

## 三、p 值寫法

- 報告**確切 p 值**到小數 2 或 3 位：*p* = .03、*p* = .012、*p* = .18。
- 小於 .001 時寫 *p* < .001，**不寫** *p* = .000（SPSS 顯示 .000 只是四捨五入）。
- 不寫 *p* = .05 以外的門檻式表達（例如 *p* < .05）作為單一結果的報告；門檻只用在表格註的星號定義。
- 不寫 *p* = NS、*p* > .05；改報確切值。
- *p* 值只到 3 位，不寫 *p* = .0004。
- 單尾檢定要註明：*p* = .02（單尾）。
- 校正後的 p 值要說明校正法：Bonferroni 校正後 *p* = .04；或表註寫「*p* 值經 Bonferroni 校正」。
- 中文句中：「*t*(38) = 2.14，*p* = .039」；英文句中：「*t*(38) = 2.14, *p* = .039」。

## 四、常用檢定的報告句型

以下每句都是可貼上的模板，方括號內為需填入的事實。

**獨立樣本 t 檢定**
> 實驗組的 SUS 分數（*M* = 78.4，*SD* = 9.6）顯著高於對照組（*M* = 70.1，*SD* = 11.2），*t*(58) = 3.02，*p* = .004，*d* = 0.79，95% CI [2.8, 13.8]。

英文：Participants in the intervention group (*M* = 78.4, *SD* = 9.6) scored higher than controls (*M* = 70.1, *SD* = 11.2), *t*(58) = 3.02, *p* = .004, *d* = 0.79, 95% CI [2.8, 13.8].

Levene 檢定不等變異時改用 Welch：*t*(52.3) = 2.96，*p* = .005，並在方法段說明。

**配對樣本 t 檢定**
> 前測（*M* = 62.3，*SD* = 12.1）到後測（*M* = 74.8，*SD* = 10.4）的分數顯著提升，*t*(29) = 5.47，*p* < .001，*d*z = 1.00，平均差 12.5，95% CI [7.8, 17.2]。

**單因子 ANOVA**
> 三組的臨床推理分數有顯著差異，*F*(2, 117) = 4.36，*p* = .015，ηp² = .07。Tukey HSD 事後比較顯示 A 組高於 C 組（*p* = .011），A 組與 B 組無顯著差異（*p* = .21）。

**重複量數 ANOVA**
> 三個時間點的分數有顯著差異，*F*(2, 58) = 12.4，*p* < .001，ηp² = .30；Mauchly 球形檢定顯著（*p* = .02），故報告 Greenhouse–Geisser 校正值，*F*(1.62, 46.9) = 12.4，*p* < .001。

**卡方檢定**
> 兩組在通過率上有顯著差異，χ²(1, *N* = 120) = 6.82，*p* = .009，φ = .24。

多於 2 × 2 用 Cramér's *V*；期望次數小於 5 的格超過 20% 時用 Fisher 精確檢定並註明。

**相關**
> 系統使用時間與 SUS 分數呈中度正相關，*r*(58) = .46，*p* < .001，95% CI [.23, .64]。

Spearman：*r*s(58) = .41，*p* = .001。括號內為 *df* = *N* − 2。

**線性迴歸**
> 迴歸模型顯著，*F*(3, 116) = 9.84，*p* < .001，*R*² = .20，調整後 *R*² = .18。年資（β = .31，*p* = .001）與使用次數（β = .24，*p* = .008）為顯著預測因子。

表格中同時列 *B*、*SE B*、β、*t*、*p*、95% CI。

**邏輯斯迴歸**
> 使用系統與通過率相關，*OR* = 2.31，95% CI [1.24, 4.30]，*p* = .008；模型 χ²(3, *N* = 120) = 14.2，*p* = .003，Nagelkerke *R*² = .15。

**無母數**
> Mann–Whitney *U* = 312.5，*z* = −2.41，*p* = .016，*r* = .22（*r* = *z* / √*N*）。
> Wilcoxon 符號等級檢定：*z* = −3.12，*p* = .002，*r* = .40。
> Kruskal–Wallis：*H*(2) = 7.85，*p* = .020。

**信度**
> 量表整體 Cronbach's α = .89（各分量表 .78–.91）。

## 五、效果量與信賴區間

- 每個推論性檢定至少報一種效果量；Cohen 慣例見 `sample-size-and-power.md` 第二節。
- 95% CI 寫成 `95% CI [下限, 上限]`，方括號，逗號後一個空格；中文句中仍用半形方括號與逗號。
- 區間屬於哪個量要講清楚：平均差的 CI、*d* 的 CI、*OR* 的 CI 分開寫。
- 「信賴區間」與「預測區間」不混用。
- 不用「trend toward significance」或「接近顯著」描述 *p* = .06；直接報數值與效果量。

## 六、中文論文的特殊慣例

- 統計符號與數字用半形；中文句的標點用全形逗號與句號：「*t*(38) = 2.14，*p* = .039。」
- 英文統計句中符號與數字間用半形逗號：「*t*(38) = 2.14, *p* = .039.」
- 中文正文的統計符號仍斜體（Word 中手動設定；標楷體內文與 Times New Roman 統計符號並存時，符號用 Times New Roman）。
- 量表名稱首次出現寫全名加縮寫：系統可用性量表（System Usability Scale, SUS）。
- 表格標題用「表 4-1」式編號（碩論）或「表 1」（期刊），表題在表格上方，註在下方。
- 全形括號用於中文敘述，半形括號用於統計自由度與引用：「三組差異顯著（*F*(2, 117) = 4.36，*p* = .015）」。

## 七、表格的 APA 樣式

結構（由上而下）：
1. **表號**：「表 1」或「表 4-1」，粗體，獨立一行。
2. **表題**：斜體（英文）或標楷體（中文碩論慣例），標題式大寫，獨立一行，簡潔說明表格內容。
3. **表頭**：每欄有欄名；統計符號斜體；欄名置中。
4. **表身**：數字對齊小數點；空白格用「—」並在註說明。
5. **註**：依序為一般註（*Note.* 或「註：」）、特定註（a、b 上標）、機率註（\*p < .05. \*\*p < .01. \*\*\*p < .001.）。

線條規則：
- 只有**橫線**：表頭上方、表頭下方、表格底部三條；必要時表頭內的跨欄橫線。
- **無直線**，無格內邊框，無底色。
- 同一欄的數字小數位一致。

範例（獨立樣本 t 檢定表）：

```text
表 2
兩組系統可用性量表分數之比較

變項           實驗組 (n = 30)     對照組 (n = 30)     t(58)    p      d     95% CI
               M      SD          M      SD
SUS 總分       78.4   9.6         70.1   11.2        3.02    .004   0.79  [2.8, 13.8]
可用性分量表   80.2   10.1        71.5   12.0        3.04    .004   0.78  [3.0, 14.4]
可學習性分量表 71.3   13.4        64.5   14.8        1.87    .067   0.48  [−0.5, 14.1]

註：CI = 信賴區間。d 為 Cohen's d。
```

## 八、圖的 APA 樣式

- **圖號**：「圖 1」粗體，獨立一行，在圖的上方。
- **圖題**：斜體（英文）或標楷體，標題式大寫，在圖號下方、圖的上方。
- 圖本體：軸標題含單位；字型無襯線（Arial、Calibri、Noto Sans TC），8 至 14 pt；黑白可讀（線型或填色區分，不只靠顏色）。
- **註**在圖的下方：說明誤差線（*SD*、*SE*、95% CI）、*n*、星號定義、縮寫。
- 誤差線一定要定義；盒鬚圖要說明盒子與鬚的規則。
- 期刊投稿的解析度與寬度以期刊官網為準（查核日期由使用者填入）；碩論 Word 插圖建議 300 dpi，寬度不超過版面（細節見 `bob-figure`）。

## 九、快速自查清單

- [ ] 拉丁統計符號斜體，希臘字母與縮寫不斜體
- [ ] *p*、*r*、α、β、η²、CVI 無前導零；*d*、*M*、*SD*、*OR* 有前導零
- [ ] 沒有 *p* = .000、*p* = NS、*p* > .05 作為單一結果
- [ ] 每個檢定都有自由度、統計量、確切 *p*、效果量
- [ ] 95% CI 用方括號，且說明是哪個量的區間
- [ ] 表題在上、註在下、無直線
- [ ] 同一統計量在摘要、正文、表格的小數位與數值一致
