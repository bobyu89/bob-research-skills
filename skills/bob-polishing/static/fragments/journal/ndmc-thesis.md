# 期刊：ndmc-thesis（國防醫學院碩士論文）

適用於國防醫學院護理學研究所碩士論文的章節潤飾與排版。格式慣例（章節結構、標楷體、全形標點、表 3-1 式編號、圖說樣式、目錄更新）見 `../../../../bob-shared/journal-formats/ndmc-thesis.md`；未確定處以所辦最新規範為準。此 fragment 通常與 `language/zh-tw.md` 同時載入；排版問題另載入 `references/word-layout.md`（本 skill 根目錄）。

## 潤飾重點

- 章節任務固定：第一章緒論（背景與動機、重要性、目的、名詞界定）、第二章文獻探討、第三章研究方法、第四章研究結果、第五章討論與結論（或分成兩章，依所方）。潤飾前先確認該段落屬於哪一章的哪一節，任務錯了先指出。
- 第一章的「研究動機」可以有臨床經驗的第一人稱敘述，但要在一到兩段內轉向文獻與問題；不要整節都是心得。
- 第二章文獻探討每節要有小結，小結不是複述而是「這一節為本研究建立了什麼」。若章節結尾是「綜合上述」開頭的段落，檢查是否真的綜合。
- 第三章的研究設計、研究對象、研究工具、資料收集、資料分析、倫理考量各自獨立成節；DBR 論文的迭代週期表要在本章。
- 第四章依研究問題或迭代週期組織；每個表格在正文有指引句，正文不重複整張表。
- 第五章的討論按研究問題逐一對話文獻；結論不出現新數字；研究限制與建議分開寫，建議分「臨床實務」「護理教育」「未來研究」依所方慣例。
- 計畫書口試後的修訂：口試委員意見的回應要落實到正文，潤飾時若看到「依委員建議修改」這類句子出現在正文，標記刪除（那是回覆表的內容）。
- 全形標點、標楷體與 Times New Roman 混排、統計符號斜體、表 3-1 式編號、圖說在圖下方、表題在表上方；細節依 `../../../../bob-shared/core/zh-tw-academic-conventions.md`。
- 內文引用 APA 7；參考文獻格式交給 `apa7-master`，本 skill 不處理 reference list。

## 常見結構問題

- 緒論太長，把第二章的內容提前寫了；移回第二章。
- 名詞界定寫成文獻回顧；改為概念性定義加操作性定義各一至兩句。
- 研究目的與研究問題不對應（三個目的、五個問題）；標記請作者對齊。
- 第四章結果混入詮釋；移到第五章。
- 第五章討論複述第四章；改為與文獻對話。
- 附錄的問卷、IRB 核准函、訪談指引沒有在正文被指引；標記。
