# 期刊：generic-health（健康科學期刊通用預設）

使用者沒有指定期刊，或目標是護理、醫學教育、數位健康領域中本 skill 沒有單獨建模的期刊時使用。格式事實以 `../../../../bob-shared/journal-formats/generic-health.md` 為準；本檔只列潤飾時的動作。

## 預設

- IMRaD 結構，摘要多為結構式（Background / Aim / Design / Methods / Results / Conclusion 或期刊指定的段名）。潤飾時先檢查摘要段名與期刊要求是否一致，再修句子。
- 引用格式預設 APA 7；期刊若用 Vancouver 或其他格式，只在修訂說明提醒，不改動引用內容。
- 讀者是跨專業的健康科學讀者（護理、醫學、教育、資訊）；專業縮寫首次出現要有全稱，臨床推理理論或 AI 技術名詞要有一句說明。
- 報告準則依研究設計（載入 `../../../../bob-shared/core/health-research-compliance.md` 決定）；潤飾時檢查方法段是否有對應準則要求的必要元素，缺少時標記。
- 主張範圍與設計一致：可用性研究不寫成效、單組設計不寫因果、單一機構不寫全國。

## 不寫死的數字

字數、圖表數、參考文獻數、摘要字數一律以期刊官網當下規定為準。若使用者需要查核，請使用者提供官網連結或自行查詢，並在修訂說明標「以期刊官網為準，查核日期 YYYY-MM-DD」。

## 選用的補充資訊

使用者有提供時採用，沒有提供時照預設處理並說明假設；不要把這些變成問卷：

- 目標期刊與摘要格式（結構式或非結構式、段名）。
- 讀者範圍（單一專業或跨專業）。
- 是否會再經過期刊或專業編輯的文字校對（影響改寫強度）。
- 是否需要同時提供中文摘要。
