# 期刊：nature-family（非預設，僅在使用者明確指定時使用）

上游的 Nature、Nature Communications、Nature Machine Intelligence 三個 fragment 已合併為本檔。Bob 的投稿目標不是 Nature 系列，所以本檔不是預設，也不再附帶任何字數或圖表上限；所有數字以期刊官網當下規定為準，並在修訂說明標「以期刊官網為準，查核日期 YYYY-MM-DD」。

## 潤飾重點

- 讀者是跨領域的廣泛讀者；開頭第一句就要讓非本領域讀者看懂問題的重要性，但不能誇大。
- 摘要多為非結構式，且不含引用；若草稿是結構式或有引用，先重組再潤飾。
- 前言不加小標題；用快速的問題漏斗（載入 `../../../../bob-shared/core/introduction-funnel.md`）。
- 結果段以主張遞進的方式組織（載入 `../../../../bob-shared/core/results-discussion-escalation.md`），不是實驗清單。
- 討論段用功能標籤重整（載入 `../../../../bob-shared/core/discussion-argument-language.md`）。
- 摘要壓縮成證據鏈（載入 `../../../../bob-shared/core/abstract-evidence-chain.md`）。
- 不用 em dash；保留語要與證據強度匹配。
- 字數、display item 數、參考文獻數、Methods 與圖說限制：一律請使用者提供官網當下規定，不從記憶引用。
- Nature Machine Intelligence 這類 AI 期刊額外注意：把 benchmark 成績與「一般智慧」「可部署」的宣稱分開；區分架構貢獻與資料、算力、調參差異；保留 Data availability 與 Code availability。
