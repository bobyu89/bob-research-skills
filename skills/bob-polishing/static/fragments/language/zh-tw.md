# 語言：學術中文（台灣繁體）潤飾

適用於碩士論文章節、台灣中文期刊投稿、計畫書、中文摘要。目標是「清楚、精確、像台灣學術圈自己寫的中文」，不是翻譯腔英文的中文版。所有規則以 `../../../../bob-shared/core/zh-tw-academic-conventions.md` 為準，本檔是潤飾時的檢查清單。

## 工作順序

1. 先讀完整段，確認段落任務（背景、缺口、目的、方法、結果、詮釋）與主題句。
2. 檢查邏輯鏈：每個主張有沒有證據、有沒有邊界。中文草稿常用「因此」「所以」連接沒有因果關係的句子。
3. 做術語帳：中文定名、英文原文、縮寫、首次出現的寫法（例如「系統可用性量表（System Usability Scale, SUS）」），之後全篇只用一種寫法。
4. 再修句子。

## 句子層次的檢查清單

### 贅字與冗詞

- 「進行……的動作」「做……的處理」「加以……」：改為動詞本身。「進行資料收集」→「收集資料」；「對問卷進行分析」→「分析問卷」。
- 「的」字串：一句超過三個「的」就重組。「本研究的研究對象的納入條件的設定」→「本研究納入條件的設定」或拆句。
- 「性」「化」「度」的濫用：「可行性」「有效性」是術語可留；「重要性的提升」→「更為重要」。
- 「一個」「一種」「一些」：多數情況可刪。「這是一種常見的現象」→「這是常見現象」。
- 「所」字冗餘：「本研究所使用的工具」→「本研究使用的工具」。
- 「等等」「等」：列舉完整時刪除；列舉不完整時用「等」即可。
- 「非常」「相當」「十分」「極為」：學術文字裡多數可刪；有統計支撐時直接寫數字。

### 翻譯腔

- 「被」字句濫用：中文的被動多數可以改為主動或無主語句。「資料被收集於……」→「資料收集自……」「於……收集資料」。有明確受害或強調受事者時才用「被」。
- 「作為……」「基於……」開頭：可改為「本研究以……為框架」「依據……」。
- 「是……的」框架：「本系統是以 RAG 技術為基礎的」→「本系統以 RAG 技術為基礎」。
- 「……之一」：「是重要的議題之一」→「是重要議題」。
- 「存在著」「有著」：「存在著差異」→「有差異」「不同」。
- 複數與冠詞的殘留：「這些研究們」「一個護理師」。
- 長定語前置：英文的關係子句直譯成十幾個字的定語，讀者要讀到最後才知道主語。拆句。
- 「當……時」「如果……的話」：多數可簡化為「……時」「若……」。
- 「它」「它們」指代不明：改為名詞本身。

### 連接詞與段落

- 「首先／其次／再者／最後」四段式排比、「此外」「另外」「同時」堆疊：每段最多一個明確的邏輯連接詞，其餘靠主題名詞承接。
- 「然而」「但是」「不過」：連續兩句都轉折是邏輯問題，不是文字問題。
- 「綜上所述」「總而言之」只在段落確實在收尾時用，且一段一次。
- 「值得注意的是」「不可否認的是」「眾所周知」：刪除或改寫成具體內容。

### 術語與名稱

- 中英對照：首次出現寫「中文（English, 縮寫）」，之後用中文或縮寫擇一，全篇一致。
- 量表與工具名稱：依作者或台灣常用譯名，全篇一致；不同段落不能一下「系統可用性量表」一下「SUS 量表」。
- 人名引用：APA 7 中文內文引用維持半形括號與逗號，例如（Tanner, 2006）、（宋建美、游明勳，2025）；中文作者之間用頓號，英文作者用「與」或「和」擇一，敘述式引用「Tanner（2006）指出」。潤飾不改動任何引用的作者、年份、頁碼。
- 「專科護理師」「進階護理師」不混用；「臨床推理」「臨床判斷」「臨床決策」依理論框架定義區分。

### 標點、數字與單位

- 全形標點：，。、；：？！（）「」『』。引用括號內的英文與數字用半形，例如（*p* < .05）、（n = 32）。
- 統計符號斜體：*M*、*SD*、*n*、*p*、*t*、*F*、*r*，數字用半形。APA 7 的 *p* 值不寫前導零（.03）。
- 數字：統計數值與測量用阿拉伯數字；十以下的計數依所方或期刊慣例，全篇一致。
- 單位與數字之間空半形空格（25 cm、3.2 秒依期刊）；百分比用「%」貼數字。
- 中英文之間是否空格依期刊或所方規範，全篇一致；預設加半形空格。
- 表題在表上方、圖說在圖下方；編號「表 3-1」「圖 4-2」（碩論）或「表 1」「圖 1」（期刊），依目標載入的 journal fragment。

## 段落層次的檢查

- 每段一個主題句，其他句子都在支撐它。
- 中文草稿常把方法寫進結果、把詮釋寫進結果；依章節任務搬回去。
- 中文的「本研究發現……」句型，一段只用一次。
- 結果段的數字要能在表格找到，且精確度一致。

## 不做的事

- 不改口語或方言用法成書面語，如果那是質性引文。
- 不把作者的保留語改強或改弱；有疑問時保留原意並標記。
- 不用大陸用語（數據→資料、軟件→軟體、質量→品質、優化→最佳化、反饋→回饋、用戶→使用者、信息→資訊）。若原稿有，改為台灣用語並在修訂說明提一句。
