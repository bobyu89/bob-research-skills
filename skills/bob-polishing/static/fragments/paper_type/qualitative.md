# 論文類型：質性研究（qualitative）

適用於主題分析、內容分析、現象學、紮根理論、個案研究、焦點團體、半結構式訪談、放聲思考等資料的論文或論文章節。這類文章的證據是「參與者說了什麼、研究者如何詮釋」，潤飾的重點是讓主題、引文、詮釋三者的關係清楚，而不是把它改寫成統計報告的語氣。

報告準則預設 COREQ（訪談與焦點團體）或 SRQR（一般質性研究）；需要決定用哪一個時載入 `../../../../bob-shared/core/health-research-compliance.md`。

## 讀者會問的問題

- 研究者用什麼立場與方法接近參與者？
- 誰被訪談、在什麼場域、為什麼是他們？
- 主題是怎麼從資料裡長出來的，不是研究者事先決定的？
- 每個主題有沒有足夠的引文支撐？引文與主題是否對得上？
- 研究者如何處理自己的影響（反身性）？
- 可信賴性（trustworthiness）的四個準則怎麼落實？

## 潤飾時要看的地方

### 方法段

- 分析方法要寫出具體步驟與出處（例如 Braun 與 Clarke 的六步驟主題分析，或 Colaizzi 的七步驟），不能只寫「採用主題分析」。
- 樣本描述要有招募方式、人數、飽和的判斷依據；「達到資料飽和」需要說明怎麼判斷。
- 訪談指引、訪談時間長度、錄音與逐字稿轉錄的說明要完整。
- 可信賴性四準則（可信性、可轉移性、可靠性、可確認性）要對應到具體作法（成員檢核、同儕審查、稽核軌跡、厚描述），不能只列名詞。
- 反身性段落要寫研究者的背景與可能影響；「研究者保持客觀」是需要改寫的句子。

### 結果段

- 每個主題的結構應是：主題名稱 → 主題說明 → 代表性引文 → 分析性評論。潤飾時檢查四者是否都在，順序是否清楚。
- 引文要有參與者代號（例如 P03），且引文本身不潤飾。口語、停頓、語助詞是資料的一部分；只能刪去與主題無關的片段並以「……」標示。
- 主題名稱不宜是抽象名詞堆疊（「壓力與調適」），較好的主題名稱能傳達參與者經驗的方向（「在不確定中反覆核對」）。
- 分析性評論與引文要分得開。常見毛病是評論只是把引文改寫成第三人稱，沒有分析。
- 不用統計語言描述質性資料：「大多數參與者」可以，「73% 的參與者顯著表示」不行；若真要報次數，用「12 位參與者中有 9 位提到」。

### 討論段

- 討論要把主題與既有文獻、理論框架對話，不是把結果再說一遍。
- 主張的範圍要與樣本一致：「本研究的專科護理師學生」不是「所有臨床學習者」。
- 「可轉移性」的討論要具體：什麼樣的場域與族群可以參考，什麼樣的不行。
- 限制段要寫這些限制對詮釋的影響，不是一句「樣本數小」帶過。質性研究的限制通常不是樣本數，而是場域單一、訪談者身分、時間點。

## 常見毛病與改法

| 毛病 | 改法 |
|---|---|
| 主題只有名稱，沒有引文 | 標記給作者補引文；潤飾不能補資料 |
| 引文與主題不符 | 標記，請作者確認歸類 |
| 「研究者保持中立客觀」 | 改為反身性描述：研究者的角色、背景、與參與者的關係 |
| 「本研究發現……具有普遍性」 | 改為有邊界的可轉移性描述 |
| 用「顯著」「證實」描述主題 | 改為「參與者描述」「浮現」「反映」 |
| 把三個主題各寫一句後就結束 | 補上主題之間的關係或整體圖像（作者提供內容） |
| 討論段複述結果 | 改為與文獻、理論框架的對話 |
| 引文被潤飾成書面語 | 還原口語，只做必要的隱私處理 |

## 英文用語提醒

- 質性研究的動詞：`emerged`、`described`、`reported`、`reflected`、`captured`；避免 `demonstrated`、`proved`、`significantly`。
- 主題名稱首字大寫並以引號或斜體標示（依期刊）；全篇一致。
- 參與者引文用直接引語，時態通常用過去式引導（`One participant noted, "..."`）。

## 中文用語提醒

- 「主題」「次主題」「類目」的層級用語全篇一致；不與「因素」「構面」混用。
- 引文前的引導句用「一位參與者提到：」，引文用「」，不用 “ ”。
- 「訪談」「晤談」「會談」擇一；「參與者」「受訪者」擇一。
