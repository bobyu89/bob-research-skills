# 輸出格式

預設輸出：

1. 潤飾後的文字，用一般段落呈現，不放在程式碼區塊裡（使用者要貼進 Word）。
2. `修訂說明：` 3 到 5 條短句，說明主要的結構與文字調整。
3. 若改寫動到章節邏輯（例如把討論段的結果複述刪掉、把結果段的詮釋移到討論），明白說出來。
4. 若有必須由作者確認的事實、數字、引用位置，列在 `請作者確認：` 之下。

使用者要求對照版時，提供：

- `原文`
- `潤飾後`
- `修改理由`

段落的結構問題若不捏造內容就無法修，寫在 `修訂說明：`，不要假裝修好了。

## 語言與格式慣例

- 潤飾學術中文時，輸出用全形標點（，。：；（）「」），引用括號內維持 APA 半形格式，例如（Tanner, 2006）、（吳淑芳等，2020）。數字、單位、統計符號依 `../../../bob-shared/core/zh-tw-academic-conventions.md`。
- 潤飾英文時，回覆的說明文字仍用繁體中文，潤飾後的正文用英文。
- 中翻英時，預設只給英文版；使用者要求才附中英對照。
- 統計數字保持作者提供的精確度，不四捨五入、不補齊。

## 觸發主文精簡時

加上一段簡短的 `主文精簡稽核：`，列出保留、改寫、壓縮、移到附錄或圖說、刪除的內容；說明主文還留下哪些描述統計與主要推論統計；報告前後字數。稽核不能蓋過潤飾後的正文。

## 觸發去 AI 腔時

在 `修訂說明：` 附上一條「AI 腔處理」，列出刪掉或改寫的套話類型（例如：開頭套話 2 處、三段式排比 1 處、連接詞 4 處）。不要逐句列表，除非使用者要求。

## 觸發排版時

排版工作（Word 或 LaTeX）不輸出潤飾後的正文，而是輸出「問題 → 操作步驟」清單，並在最後提醒使用者重新檢視整份文件的分頁結果。
