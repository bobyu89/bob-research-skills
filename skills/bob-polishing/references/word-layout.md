# Word 排版（碩士論文與中文期刊投稿）

適用於使用者要求「排版」「表格跨頁」「圖說跑掉」「目錄沒更新」「頁碼不對」「字型混亂」等 **位置與格式** 問題，而非文字內容。載入本檔時跳過 paper_type、section、language 的潤飾流程；輸出「問題 → 操作步驟」清單，不輸出潤飾後的正文（見 `../static/core/output-format.md`）。

需要直接對 .docx 檔操作（批次改字型、插入表格、產生目錄）時，交給 `docx` skill；本檔負責告訴使用者或 docx skill「要做什麼、為什麼」。所方格式規範以 `../../bob-shared/journal-formats/ndmc-thesis.md` 與所辦最新公告為準；本檔的做法是通用操作，不是規定。

## 1. 診斷順序

1. 開啟「顯示所有格式化標記」（¶）。多數排版問題來自看不見的分頁符、分節符、手動空行、Tab。
2. 開啟「導覽窗格」確認標題階層是否用樣式（標題 1、標題 2）而不是手動加粗放大；沒有用樣式，目錄和交互參照都不可靠。
3. 用「樣式」窗格看正文是否統一在同一個樣式（例如「內文」或自訂的「論文內文」），而不是每段直接格式化。
4. 檢查段落設定裡的「分頁」頁籤（段落前分頁、與下段同頁、段落中不分頁、孤行控制）。
5. 一次只改一類問題，改完滾一遍全文再改下一類。Word 的分頁是連鎖反應，前面一改後面全變。

## 2. 字型：標楷體與 Times New Roman 混排

台灣論文慣例是中文字用標楷體、英文與數字用 Times New Roman。Word 的字型設定分「中文字型」與「英文字型」（拉丁文字）兩個欄位，正確做法是在樣式裡分別設定，不是逐段手動選。

- 修改「內文」樣式 → 字型 → 中文字型：標楷體；字型（拉丁文字）：Times New Roman；字型大小依所方規範（示例：12 點）。
- 標題樣式同樣分別設定；粗體與大小依所方規範。
- 表格內文與圖說常用較小字級（例如 10 或 11 點），建立「表格內文」「圖說」自訂樣式，不要每格手動改。
- 常見毛病：全選後直接套 Times New Roman，中文變成新細明體或微軟正黑體；或全選套標楷體，英文變成標楷體英文（字距怪異）。修法是分別設定兩個欄位。
- 全形標點在標楷體下顯示正常；若標點看起來是半形或字距怪，多半是段落被套了英文字型當中文字型。
- 統計符號斜體（*p*、*t*、*M*、*SD*）在 Times New Roman 下設定；不要用標楷體斜體。
- 特殊符號（≥、±、α、χ²）用 Times New Roman 或 Symbol，全篇一致；避免從網頁貼上帶來的 Cambria Math。

## 3. 段落：間距、縮排、對齊

- 行距與段落間距依所方規範（常見固定行高或 1.5 倍行高，段前段後 0 點）；在「內文」樣式設定，不逐段調。
- 首行縮排用段落設定的「第一行縮排 2 字元」，不用空格或 Tab。
- 中文正文常用「左右對齊」；若英文段落出現字距被拉開的情況，檢查是否有多餘的手動換行（Shift+Enter）。
- 標題前後的間距在標題樣式裡設，不用空行；空行會在分頁處造成頁首空白。
- 清除多餘空行：用「尋找及取代」把兩個連續段落標記（^p^p）換成一個（^p），先確認沒有刻意保留的空段。
- 中英文之間的間距：Word 的「自動調整中文與英文的間距」選項可以開，但要全篇一致；若期刊要求半形空格，就關掉此選項並手動加。

## 4. 表格：跨頁、標題列重複、三線表

- 表格跨頁時，選取標題列 → 表格內容 → 列 → 勾選「在各頁頂端以標題列重複」。這樣續頁自動出現標題列。
- 防止單一列被拆到兩頁：表格內容 → 列 → 取消「允許列超越頁面分隔線」。
- 表題在表上方，用「表題」樣式或標號功能（參考資料 → 插入標號 → 標籤「表」）；碩論常用「表 3-1」章節式編號，需在標號設定「包含章節編號」並確認標題 1 有用多層次清單編號。
- 表題與表格要「與下段同頁」（段落 → 分頁 → 與下段同頁），避免表題落在上一頁尾。
- 表格太長時，考慮拆表或轉為附錄；不要縮字到 8 點。
- 三線表：只保留上框線、標題列下框線、表格下框線。用「框線」工具或建立表格樣式；表內不加垂直線。
- 表格內數字對齊：小數點對齊可以用「靠右」加固定小數位數；統計表的欄位寬度依內容微調，不要讓 *p* 值欄折行。
- 表格註解（Note. 或「註：」）放在表格下方，字級與表格一致，斜體與 *p* 值註記格式依 APA 7。
- 表格跨頁且被規範要求時，續頁表題寫「表 3-1（續）」；用手動方式加在續頁第一列上方，或把表拆成兩個表格物件。

## 5. 圖與圖說：位置、編號、避免與正文分離

- 圖片文繞圖設為「與文字排列」（inline），不要用「緊密」或「上及下」；浮動圖片是圖說跑掉、圖跨頁的主因。
- 圖說在圖下方，用標號功能（標籤「圖」）；「圖 4-2」章節式編號同表格作法。
- 圖與圖說要同頁：把圖所在段落設「與下段同頁」，圖說段落設「段落中不分頁」。
- 圖片解析度：投稿常要求高解析度（示例：300 dpi 以上，以期刊官網為準）；Word 預設會壓縮圖片，在檔案 → 選項 → 進階 → 影像大小與品質，勾選「不要壓縮檔案中的影像」並設定預設解析度為高保真。
- 圖片寬度不超過版面寬度（A4 加 2.5 公分邊界約 16 公分）；等比例縮放，不要只拉一邊。
- 圖中的中文字型要能在 PDF 中正確嵌入；用標楷體或 Noto Sans TC，避免在圖裡使用系統沒有的字型。
- 多張小圖組成的圖，建議先在繪圖軟體合併成一張再插入，並用 (a)(b)(c) 標示；不要在 Word 用表格拼圖。
- 圖說寫法：「圖 4-2 各迭代週期之 SUS 平均分數」，句尾是否加句號依所方；圖說要能獨立閱讀。

## 6. 標題與孤行：避免標題落在頁尾、段落末行孤立

- 所有標題樣式設定「與下段同頁」，標題就不會單獨留在頁尾。
- 內文樣式開啟「孤行控制」（段落 → 分頁），Word 會避免段落首行或末行單獨落在另一頁。
- 章標題「段落前分頁」在標題 1 樣式設定，不用手動插入分頁符。
- 章末剩半頁空白是正常的；不要為了填滿而調整行距。
- 節標題落在頁尾後面只剩一行正文：把該標題設「與下段同頁」通常就解決；還是不行時檢查前面是否有手動分頁或空行。
- 手動分頁符（Ctrl+Enter）只用在章與章之間；其他地方一律用段落分頁設定。

## 7. 分節、頁碼與頁首

- 論文常見頁碼規則：封面不編頁、前置頁（摘要、目錄）用羅馬數字、正文從第一章起用阿拉伯數字從 1 開始。做法是在前置頁與正文之間插入「分節符（下一頁）」，然後在正文第一節的頁尾取消「連結到前一節」，再設定頁碼格式「起始頁碼 1」。
- 每個分節符都是一個獨立的頁首頁尾設定；分節符太多會造成頁碼跳號。先在 ¶ 模式下清點分節符數量，非必要的刪掉。
- 頁碼位置與字型依所方規範；頁碼字型通常用 Times New Roman。
- 橫向頁面（大表格）需要獨立分節：前後各一個分節符（下一頁），該節設為橫向；頁碼位置要另外處理，通常橫向頁的頁碼仍要出現在與直向頁相同的位置，需用文字方塊或旋轉頁碼。
- 頁首若要顯示章名，用 StyleRef 功能變數引用標題 1，不要手打。

## 8. 目錄、圖目錄、表目錄的更新

- 目錄用「參考資料 → 目錄 → 自訂目錄」自動產生，依標題樣式階層；手打的目錄一改內文就錯。
- 圖目錄與表目錄用「插入圖表目錄」，依標號標籤「圖」「表」產生。
- 更新方式：點進目錄 → F9（或右鍵 → 更新功能變數）→ 選「更新整個目錄」。交付前一定要更新，因為 Word 不會自動更新目錄頁碼。
- 全文功能變數一次更新：Ctrl+A 全選後按 F9，會同時更新目錄、圖表目錄、交互參照；有些版本會跳出多個對話框，逐一選「更新整個目錄」。
- 目錄出現不該有的項目（例如某段內文被誤套標題樣式）：回到該段落改回內文樣式，再更新目錄。
- 目錄字型：目錄樣式（目錄 1、目錄 2）也要分別設中文與英文字型，否則目錄會是新細明體。
- 交互參照（「見表 3-1」）用「參考資料 → 交互參照」插入，表格重新編號時才會跟著變。

## 9. 交付前檢查清單

- [ ] 所有標題使用標題樣式，導覽窗格階層正確。
- [ ] 內文、表格內文、圖說、目錄樣式的中文與英文字型分別設定。
- [ ] 沒有用空行或 Tab 做的間距與縮排；連續空段已清除。
- [ ] 跨頁表格有標題列重複，列不跨頁；表題與表格同頁。
- [ ] 圖片為與文字排列，圖與圖說同頁，解析度未被壓縮。
- [ ] 所有標題「與下段同頁」，內文開啟孤行控制。
- [ ] 分節符數量最少；頁碼格式（羅馬與阿拉伯）與起始頁碼正確。
- [ ] 目錄、圖目錄、表目錄已用 F9 更新，且無誤入項目。
- [ ] 統計符號斜體、全形標點、中英間距全篇一致。
- [ ] 另存 PDF 後逐頁翻看一次；Word 畫面與 PDF 可能不同。
