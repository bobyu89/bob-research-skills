# 去 AI 腔清單（學術英文與學術中文）

適用於使用者說「去 AI 腔」「太像 AI 寫的」「看起來像 ChatGPT」「降 AI 感」時。目標是讓學術文字讀起來像一位謹慎的研究者寫的，而不是把學術文字改成口語。**口語化、講人話、給病人或大眾看的版本，轉交 `speak-human-tw`。**

去 AI 腔不是換同義詞。AI 腔的根源是「沒有具體內容的句子」與「機械的結構」，所以修法優先是：刪掉沒有資訊的句子、把泛稱換成具體事實、把排比拆成論證。改完後每一句都要能回答「這句在這段的功能是什麼」。

紅線不變：不捏造內容。去 AI 腔時若發現一句話刪掉後段落沒有實質內容，那是內容問題，寫進修訂說明請作者補，不要用另一種套話填回去。

## 一、學術英文

### 1. 套話開頭（刪除或改為具體問題）

- `In recent years, ...` / `In today's rapidly evolving healthcare landscape, ...`
- `With the rapid development of artificial intelligence, ...`
- `It is widely acknowledged that ...` / `It is well known that ...`
- `Nursing plays a vital role in ...` / `... has become increasingly important.`
- `In the realm of ...` / `In the ever-changing world of ...`
- `This paper aims to explore ...`（前言第一句就寫目的）

改法：以具體的臨床或教育問題開頭，附上一個可查證的事實或引用。

### 2. AI 偏好詞（換成普通學術用語）

| 常見 AI 用詞 | 改為 |
|---|---|
| delve into | examine, investigate |
| leverage, harness | use, apply |
| tapestry, landscape, realm | 刪除或改具體名詞 |
| pivotal, crucial, paramount, vital | important（或刪除，讓證據說話） |
| robust（非統計語境） | 刪除或改 consistent |
| seamless, seamlessly | 刪除 |
| foster, cultivate, empower | support, promote, enable |
| holistic | comprehensive（或刪除） |
| navigate（抽象用法） | manage, address |
| underscore, highlight（每段都有） | show, indicate（一段最多一次） |
| showcase | show, present |
| unlock, unleash | enable |
| paradigm shift, game-changer | 刪除 |
| multifaceted, nuanced | 刪除或寫出具體面向 |
| a testament to | 刪除 |
| it is worth noting that, notably（頻繁） | 刪除，直接寫內容 |
| ultimately, at the end of the day | 刪除 |
| comprehensive（用來形容自己的研究） | 刪除 |

### 3. 結構性 AI 腔

- 三段式排比：`Firstly ... Secondly ... Thirdly ...`、`not only ... but also ...`、三個形容詞並列（`efficient, effective, and scalable`）。拆成論證，或只留有證據支撐的那一項。
- 每段結尾都是總結句（`Overall, these findings highlight ...`）：一節只留一個總結。
- 每句都有連接詞（`Moreover`, `Furthermore`, `Additionally`, `Consequently`）：一段最多兩個，其餘靠名詞承接。
- 對稱句型（`While X offers ..., it also presents ...`）連續出現：改為直接陳述。
- 條列式思考硬塞進段落（一段內三個 `First/Second/Third`）。
- 「先肯定再轉折」模板（`Although prior studies have made significant contributions, they have limitations.`）：改為指名具體的限制。
- 空泛的限制段（`Future research should explore this topic further with larger samples.`）：每條限制要對應到某個主張的邊界。
- 空泛的意涵段（`These findings have important implications for nursing education.`）：寫出是什麼意涵、對誰、在什麼條件下。

### 4. 保留語與強度的機械化

- 每句都加 `may` 或每句都 `demonstrates`：依證據強度分配（見 `phrasebank-playbook.md`）。
- `significantly` 沒有統計檢定：改 `substantially` 或刪除。
- `potentially`、`possibly`、`could potentially` 疊加：留一個。

### 5. 檢查方式

改完後，隨機抽三句，各問：這句刪掉段落會少什麼？答案是「什麼都不少」的句子就刪。

## 二、學術中文

### 1. 套話開頭（刪除或改為具體問題）

- 「隨著科技的進步／隨著人工智慧的蓬勃發展……」
- 「近年來，……日益受到重視。」
- 「在當今……的時代背景下」
- 「眾所周知」「不可否認的是」「毋庸置疑」
- 「護理人員在……扮演著重要的角色」
- 「本文旨在探討……」放在第一句

改法：以具體問題、數字或文獻開頭。

### 2. AI 偏好詞與句型

| 常見 AI 用詞 | 改為 |
|---|---|
| 值得注意的是 | 刪除，直接寫內容 |
| 首先／其次／再者／最後（四段排比） | 拆成論證；最多留兩個 |
| 此外／另外／同時／再者（連續使用） | 一段最多一個 |
| 綜上所述／總而言之（每段都有） | 一節一次 |
| 賦能、賦予、深耕、打造 | 支持、建立、提供 |
| 全方位、多元化、多面向（無具體內容） | 刪除或列出面向 |
| 至關重要、不可或缺、舉足輕重 | 重要（或刪除） |
| 有效提升、大幅改善（無數字） | 附數字，或改「參與者自陳……」 |
| 深入探討、深入了解 | 探討、了解 |
| 有助於、有利於（每句都有） | 改具體動詞或刪除 |
| 進一步地、更進一步 | 刪除 |
| 一方面……另一方面…… | 只在真正對比時用 |
| 不僅……更…… | 改直述句 |
| 可以說、可謂 | 刪除 |
| 在……方面 | 多數可刪 |
| 進行……的動作、加以……、予以…… | 改動詞本身 |
| 具有一定的……、某種程度上 | 刪除或寫明程度 |

### 3. 結構性 AI 腔

- 每段結尾「由此可見」「因此，……具有重要意義」：一節留一個。
- 每段都是「主張句 → 三個支持點 → 總結句」的固定形狀：打散，讓段落長度與內容量對應。
- 排比句（「提升效率、改善品質、增進滿意度」）：只留有證據的。
- 文獻回顧每段都是「A 學者（年）指出……；B 學者（年）認為……；C 學者（年）發現……」：改為依論點組織，作者放括號。
- 「本研究發現……」「本研究結果顯示……」每段開頭：一段一次。
- 空泛的建議（「建議未來研究可擴大樣本數，並納入不同族群」）：對應到本研究的具體限制。

### 4. 中文特有的機械感

- 「的」字串與「性」「化」濫用（見 `../static/fragments/language/zh-tw.md`）。
- 「進行」「做」「加以」當萬用動詞。
- 被動句「被……」與「受到……的影響」濫用。
- 全篇都是四字語（「循序漸進」「相輔相成」「與時俱進」）。

### 5. 檢查方式

- 抽三句問「刪掉會少什麼」。
- 找出全篇出現超過三次的連接詞與套語，列表給作者。
- 讀一遍段落開頭的第一個詞；若連續多段都是「此外」「然而」「因此」，改結構不是改字。

## 三、與其他 skill 的分工

| 需求 | 交給 |
|---|---|
| 學術英文或學術中文去 AI 腔，維持學術體 | 本檔（bob-polishing） |
| 台灣口語、講人話、社群貼文、衛教文、給大眾看的版本 | `speak-human-tw` |
| 整章從零撰寫時內建的 AI 痕跡消除 | `academic-writing` 的 humanize 流程 |
| 只是要改換句式讓偵測器分數變低 | 不做。本 skill 只處理文字品質，不對付偵測器 |
