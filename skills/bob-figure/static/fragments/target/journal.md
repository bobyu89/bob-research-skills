# 交付目標：期刊投稿級圖件（journal）

適用於期刊投稿、修訂稿、審查回覆附圖與英文稿件中的圖。本片段規定匯出契約與圖說慣例；字型與尺寸的具體數字**以目標期刊官網的 author guidelines 為準**，本片段只給預設值與查核方法。

## 匯出契約

| 項目 | 預設 | 備註 |
|---|---|---|
| 檔案格式 | **向量 PDF 或 SVG**（文字可編輯：matplotlib `pdf.fonttype = 42`、`svg.fonttype = "none"`；R 用 `cairo_pdf`、`svglite`） | 期刊要求 TIFF／EPS 時再由同一後端另存；含顯微或截圖的面板可用 TIFF（300 dpi 以上），純線圖仍交向量 |
| 圖寬 | 依期刊的單欄／雙欄寬度 | 投稿前到期刊官網查「figure width」或「column width」，把查到的數值與**查核日期**記在圖件契約；未查到前以「單欄約 8 到 9 cm、雙欄約 17 到 18 cm」作示例值規劃，不當定案 |
| 字型 | **Arial 或 Helvetica**（無襯線），整張圖一種字型 | 若期刊指定其他字型以期刊為準；統計符號斜體依 APA 7 |
| 字級 | 以最終尺寸量測，內文標籤 7 到 9 pt，最小不低於 5 pt（`scripts/audit_pdf_text.py` 的下限） | 面板標籤粗體 8 到 10 pt，小寫 a、b、c 或大寫 A、B、C 以期刊為準 |
| 顏色 | **色盲友善**（Okabe-Ito 或 viridis 系列），避免紅綠對比承載唯一資訊 | 同時確認灰階列印仍可辨識；印刷彩色費用以期刊為準 |
| 線寬 | 座標軸 0.5 到 0.8 pt，資料線 1 到 1.5 pt | 誤差線與資料線區分粗細 |
| 背景 | 白底、無外框、去多餘格線 | 影像類面板才用深色背景 |

## 圖說慣例

- 圖說（figure legend／caption）放在稿件正文或圖說頁，**不畫進圖片**；圖說字數上限以期刊為準並標查核日期，沒有規定時以「一段可獨立閱讀的說明」為原則。
- 結構：粗體短標題（名詞片語） → 逐面板一句話（a、b、c） → 統計說明（樣本數 *n*、誤差線定義、檢定與 *p* 值格式） → 資料來源或授權。寫法細節載入 `references/figure-legend-conventions.md`。
- 統計數字只放已由 `bob-statistics` 確認過的結果；圖說中的統計格式依 APA 7。
- 面板標籤、顏色對應、縮寫在圖說內自足，讀者不看正文也能理解。
- 護理與醫學教育期刊常要求：圖中不出現可識別受試者的資訊（姓名、病歷號、臉部）、系統截圖需去識別化；相關規範載入 `../bob-shared/core/health-research-compliance.md`。

## 常見期刊的查核項目（不寫死數字）

投稿前對目標期刊逐項查核並記錄日期：

| 查核項目 | 記錄格式 |
|---|---|
| 單欄／雙欄寬度與最大高度 | 「JAN 雙欄 ___ mm，查核 YYYY-MM-DD」 |
| 接受的檔案格式與解析度 | 「TIFF 300 dpi／EPS／PDF，查核 YYYY-MM-DD」 |
| 圖說字數上限 | 「___ 字或未規定，查核 YYYY-MM-DD」 |
| 主圖數量上限 | 「___ 張或未規定，查核 YYYY-MM-DD」 |
| 彩色圖費用與線上／印刷差異 | 「___，查核 YYYY-MM-DD」 |
| 補充資料圖的格式 | 「___，查核 YYYY-MM-DD」 |
| AI 生成圖像政策 | 「允許／禁止／需揭露，查核 YYYY-MM-DD」 |

JMIR 系列的 multimedia appendix、台灣中文期刊的中英圖說並列等特殊要求，屬於期刊格式而非繪圖本身，交付時提醒使用者到 `bob-writing` 的期刊片段確認。

## 交付清單

1. 向量 PDF（主交付）與 SVG（可編輯）。
2. 期刊要求時的 TIFF／EPS（同一後端匯出）。
3. 圖說文字（英文，依 APA 7 統計格式）。
4. 資料來源表（source data）與排除紀錄。
5. 對齊 JSON、PDF 字級稽核結果、碰撞稽核 JSON。
6. 圖件契約（含期刊查核項目與日期）。
